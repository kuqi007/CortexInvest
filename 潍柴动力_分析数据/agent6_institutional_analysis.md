2. **传统重卡业务**
   - 2026年重卡行业预计稳定增长
   - 核心市场占有率稳步提升
   - 高端产品贡献率提升

3. **大缸径发动机**
   - 2025年销量首次突破1万台
   - 收入58.1亿元，同比增长65%

4. **新能源动力系统**
   - 收入翻倍增长

5. **凯傲集团**
   - 2026年收入预计114-123亿欧元 (+1%-9%)
   - 调整后EBIT预计8.5-10.4亿欧元 (+8%-32%)

### 4.4 转型故事 (机构视角)

```
传统制造业(15倍PE) → 科技能源股(22倍PE)
        ↓
   AIDC业务重估
        ↓
数据中心发电设备供应商
        ↓
AI基础设施受益者
```

**关键转型逻辑**:
- 从"重卡发动机制造商"转型为"综合动力系统+能源解决方案提供商"
- AIDC业务带来估值体系切换（制造业→科技股）
- 海外收入占比超50%，全球化布局完善
- 分红比例持续提升，股东回报改善
