# 潍柴动力估值分析报告

## 一、股票类型分类

### 分类结果：**Transformation（转型期）+ Cyclical（周期性）**

### 分类理由：

| 维度 | 分析 | 结论 |
|------|------|------|
| **传统业务** | 重卡发动机、整车业务占收入75%，受宏观经济周期影响明显 | Cyclical |
| **新业务转型** | AIDC（数据中心）发动机、新能源动力系统、大缸径发动机高速增长 | Transformation |
| **成长性** | 2025年AIDC发动机销售1400台（+259%），新能源收入30.4亿（+97%） | Growth特征 |
| **盈利性** | ROE 12.15%，净利润109亿，分红率58%，具备Value特征 | Value特征 |

**核心判断**：潍柴动力正处于从传统重卡制造商向"动力系统综合解决方案提供商"转型的关键期，AIDC业务可能成为第二增长曲线。同时，传统重卡业务具有明显的周期性特征。

## 三、估值方法说明

### 3.3 PEG估值法（适用：成长股）

**增长率估算：**
- 2025年营收增长：+7.47%
- 2026年营收指引：+8%-12%
- 新业务（AIDC+新能源）增速：>100%
- 综合盈利增长率(g)估计：10%-15%（取中值12.5%）

**PEG计算：**
| 指标 | 数值 |
|------|------|
| 当前PE(TTM) | 21.6倍 |
| 盈利增长率(g) | 12.5% |
| PEG | 1.73 |

**判断**：PEG=1.73 > 1.0，当前估值相对成长性略显偏高。

**PEG目标价（目标PEG=1.0）：**
- 合理PE = g × 1.0 = 12.5倍
- 目标价 = 1.25元 × 12.5 = **15.63元**

*注：PEG估值结果偏低，主要因公司处于转型期，传统业务拖累整体增速，PEG法适用性有限。*

### 5.2 估值结论

**核心观点：当前股价(27元)处于合理偏高区间，上行空间有限**

| 维度 | 分析 |
|------|------|
| **绝对估值** | 综合估值21-26元，当前27元溢价约4%-28% |
| **相对估值** | PE 21.6倍 vs 国际AIDC对标34倍，存在折价；但vs传统制造业15倍，存在溢价 |
| **机构预期** | 机构一致目标价35.7元，较现价+32%，反映转型乐观预期 |
| **安全边际** | 当前价位安全边际不足，建议等待回调至24元以下再考虑介入 |

## 六、风险提示

1. **周期性风险**：重卡行业与宏观经济高度相关，若经济下行将拖累业绩
2. **转型风险**：AIDC业务占比仍小，能否成为第二增长曲线存在不确定性
3. **估值风险**：当前PE已反映一定转型预期，若进展不及预期存在回调压力
4. **竞争风险**：AIDC发动机领域面临康明斯、卡特彼勒等国际巨头竞争
