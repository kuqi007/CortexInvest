# 潍柴动力业务进展

## 核心业务板块

### 1. 动力系统业务
- 发动机销售74.3万台，同比增长1.3%
- 出口7.5万台，同比增长8%
- 16M33双燃料、12M55NG成功导入矿卡动力
- 非道路甲醇发动机市占率行业第一
- 牵头推动全球首批氢内燃机国际标准预研

### 2. 新能源动力系统
- 收入30.4亿元，同比增长97%
- 动力电池销售6.3GWh，同比增长162%
- 电机销量同比增长219%
- 电机控制器销量同比增长56%
- 烟台新能源动力产业园一期投产

### 3. 电力能源业务 (AIDC核心)
- 2025年成为第七大业务板块
- 发电用发动机销售10.4万台，同比增长15%
- **大缸径发动机销量突破1万台，同比增长32%，收入58.1亿元，同比增长65%**
- **数据中心用发动机销售约1400台，同比增长259%**
- 推出全球首款5兆瓦级高速柴油发电产品20M61
- SOFC发电系统通过欧盟CE认证，最高发电效率超65%
- 与英国希锂斯签订制造许可协议，布局全产业链

### 4. 商用车业务
- 子公司陕重汽整车销量15.3万辆，同比增长29.4%
- 新能源重卡2.5万辆
- 出口5.9万辆

### 5. 智慧物流 (凯傲集团)
- 收入113亿欧元
- 调整后EBIT 7.9亿欧元
- 2026年指引：收入114-123亿欧元(+1%-9%)，EBIT 8.5-10.4亿欧元(+8%-32%)

### 6. 农业装备
- 收入180.2亿元
- 净利润9亿元
- 海外收入23.8亿元，同比增长38.2%

## 2026年增长驱动力
1. 重卡行业规模稳定增长
2. 凯傲集团订单高增
3. 数据中心产品推广加速
4. 矿山和挖机市场突破
5. 海外市场拓展

## 竞争优势
1. **AIDC先发优势**：数据中心备用电源销量同比增长259%
2. **技术领先**：全球首款5MW级高速柴油发电产品
3. **海外渠道**：PSI公司深耕北美市场，发电产品收入占比81%
4. **全产业链**：SOFC电池、电堆、系统全产业链布局
