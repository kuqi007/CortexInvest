# AI Stock Notes — 股票交易备忘录

## 用途

每只股票一个 markdown 文件，用于保存：
- 复杂的交易计划（比 trade_plans.json 更灵活的文字描述）
- AI 分析结论和历史推理记录
- 关键观察点和决策逻辑
- 持仓理由和风险提示

**核心目标：防止 AI 失忆。** 下次用户询问同一只股票时，AI 先读取该文件，基于历史分析给出连贯建议。

## 文件规范

### 路径
```
.claude/notes/{CODE}.md
```

如：`.claude/notes/HK03858.md`

### 命名
- 使用股票代码作为文件名（大写）
- 港股：`HKxxxxx.md`
- A股：`SHxxxxxx.md` / `SZxxxxxx.md`

### 内容格式（推荐）

```markdown
# {股票名称} ({CODE}) — AI 交易备忘录

## 当前持仓
- 状态：holding / watching / 空仓
- 成本：xx 元
- 股数：xxx
- 当前浮亏/浮盈：xxx

> 若已清仓：记录清仓时间、清仓价、前持仓成本、实际盈亏

## 关联程序交易计划
- 状态：有 / 无
- 说明：如有 trade_plans.json 中的自动计划，简述与文字计划的差异或补充

## 交易计划（文字版）
- 买入区间：xx-xx
- 止损位：xx
- 目标位：xx
- 加仓条件：xxx

## 核心逻辑
（为什么关注这只股票，行业逻辑、催化剂等）

## 关键观察指标
（需要跟踪的变量，如商品价格、业绩、政策等）

## 下次触发条件
- 若 X 发生 → 关注/建仓/加仓
- 若 Y 发生 → 止损/离场

## AI 历史分析记录

> 新条目写在最上方（倒序），保持最新分析优先可见。

### 2026-04-24
（今天的分析结论，决策建议）

### 2026-04-20
（之前的分析，如有）
```

## 使用规则

### 对用户
- 随时可以说"帮我在 {CODE} 的 notes 里加上..."
- 也可以说"读一下 {CODE} 的 notes"
- 交易计划变更时，主动要求更新 notes

### 对 AI
- **每次用户询问某只股票时，先读取对应的 notes 文件**
- 基于 notes 中的历史分析，给出连贯的、不重复的建议
- 分析结束后，主动将新结论追加到 notes 中
- 如果 notes 不存在，创建它并写入初始分析

## 与 trade_plans.json 的区别

| 特性 | trade_plans.json | AI Notes |
|------|------------------|----------|
| 格式 | 结构化 JSON | 自由 Markdown |
| 用途 | 程序执行（自动触发） | AI 决策参考（人工+AI 阅读） |
| 内容 | 价格、股数、触发条件 | 分析逻辑、观察指标、历史结论 |
| 更新 | 通过 Web UI / API | 通过对话让 AI 写入 |
| 谁用 | 程序（tick_monitor 等） | AI + 用户 |

两者互补：trade_plans 负责**执行层**，notes 负责**决策层**。
