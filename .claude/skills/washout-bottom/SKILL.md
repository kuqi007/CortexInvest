# 洗盘底部买入信号

## 双策略说明

工具同时输出两种策略，选择更适合的那一个作为决策依据：

### 策略A：黄金坑（固定 20-25%）

```
保守买入 ≈ 高点日收盘价 × 0.80
激进买入 ≈ 高点日最高价 × 0.75
```

主力洗盘通常从高点回落约 20-25%，达到黄金坑区间。
**适用**：波动相对稳定的行业龙头、成长股。

### 策略B：ATR 支撑位（自适应波动率）

```
ATR(14) = 14日平均真实波幅（Wilder's EMA）
保守支撑 = 近低点 + 1.5 × ATR
激进支撑 = 近低点 + 2.0 × ATR
```

当前价低于支撑位 = 超跌区；支撑位附近是较好买入点。
**适用**：波动大的周期股、题材股、高弹性标的。

## 适用场景

- **基本面优秀的 A 股**（行业龙头、成长性标的）
- 不适用于：ST 股、垃圾股、港股、美股
- 目的：中长线建仓，寻找主力洗盘后的最佳买点

## 运行工具

```bash
uv run python -m src.tools.washout_calculator --code <股票代码> --days <回溯天数>

# 示例
uv run python -m src.tools.washout_calculator --code 002438 --days 90

```

## 策略选择指南

| 情况 | 推荐策略 |
|------|---------|
| 股价接近前高、波动稳定 | 策略A（黄金坑）更准确 |
| 股价已大跌、波动剧烈 | 策略B（ATR）更合理 |
| 两只股票对比 | ATR 策略更标准化，可跨股票比较 |

## 均线分析 (MA)

工具计算 MA5 / MA10 / MA20 / MA60，判断：

| 状态 | 含义 |
|------|------|
| 价格在 MA20/MA60 **下方** | 确认下跌趋势，未企稳 |
| 均线**空头排列**（MA5>MA10>MA20>MA60）| 下跌趋势中，洗盘可能未结束 |
| 均线**多头排列**（MA5<MA10<MA20<MA60）| 上升趋势，回调低点可能是好买点 |
| 距 MA20 跌破 5%+ | 加速下跌中，需等待 |
| 距 MA60 跌破 5%+ | 中线趋势走坏，不宜抄底 |

**买入偏好**：
- ✅ 均线多头排列 + 价格接近洗盘区间 = 强信号
- ✅ 均线空头排列 + 价格跌破 MA60 + 洗盘区间到位 = 二次确认
- ⚠️ 均线空头排列 + 距 MA20 仍远 = 过早抄底

## 布林带分析 (BOLL)

| 指标 | 含义 |
|------|------|
| `%B < 0` | 价格跌破下轨，超卖信号 |
| `%B < 0.2` | 接近下轨，低位区域 |
| `%B 0.2~0.8` | 中轨附近，正常波动 |
| `%B > 0.8` | 接近上轨，偏贵 |
| 带宽 < 5% | 极度收敛，**可能变盘**（重点关注）|
| 带宽 5~10% | 收敛状态，观望 |
| 带宽 > 20% | 扩张状态，趋势中 |

**买入偏好**：
- ✅ `%B < 0.2` + 洗盘区间到位 = 低位共振
- ✅ 带宽 < 5%（BOLL 收口）+ 之后放大阳线 = 洗盘结束信号
- ⚠️ `%B > 0.8` + 未到洗盘区间 = 不是好买点

## RSI 分析（Wilder's EMA）

| 周期 | 用途 |
|------|------|
| RSI(6) | 短期超买超卖，灵敏度高 |
| RSI(12) | 中期趋势判断 |
| RSI(24) | 长期趋势确认 |

RSI(6) < 30 或持续下行未稳 = 尚未见底；RSI(6) 金叉 = 企稳信号。

## 综合信号强度

| 条件 | 信号强度 |
|------|---------|
| 双策略共振（均在区间）+ MA空头排列 + %B<0.2 | ⭐⭐⭐⭐⭐ 强 |
| 洗盘区间到位 + MA空头排列 + %B<0.2 | ⭐⭐⭐⭐ 超跌共振 |
| 洗盘区间到位 + MA多头排列 + %B 0.2~0.5 | ⭐⭐⭐ 中（回调买入）|
| 洗盘区间到位 + 仅MA空头排列 | ⭐⭐ 弱（需等企稳）|
| 未到洗盘区间 + %B>0.8 | ⭐ 不考虑 |

## 使用流程

1. 用户询问某只股票是否到洗盘底部买点
2. 运行工具，对比策略A（黄金坑）和策略B（ATR）
3. 选择更适合当前市况的策略作为主参考
4. 分析 MA + BOLL + RSI：
   - MA 是否空头排列？%B 是否低位？
   - 带宽是否收敛（变盘前兆）？
   - RSI(6) 趋势？
5. 综合判断信号强度，给出操作建议
6. 用户确认后，创建 trade_plan 条件单
