# 股票统一分析系统 (Unified Stock Analysis)

> **设计理念**: 一个入口，智能分类，自动匹配最优估值方法

---

## 使用方式

```text
# Skill 调用示例（不是 shell 命令）
/stock-analysis-unified 某价值股
/stock-analysis-unified 某转型股
/stock-analysis-unified 某成长股
```

---

## 工作流程

```
用户输入股票名
    ↓
Step 1: 数据收集 (mx-data + mx-search)
    ↓
Step 2: 智能分类 (多维度评分)
    ↓
Step 3: 匹配估值方法 (主方法 + 条件触发双轨)
    ├─ 价值股 → PE/PB/股息率
    ├─ 成长股 → PEG/Forward PE/DCF
    ├─ 周期股 → 正常化PE/PB
    ├─ 转型股 → SOTP
    │   └─ 若重大并表 / pro forma → 追加 Forward PE/PEG/EV
    └─ 亏损股 → PS/终局估值
    ↓
Step 4: 执行估值计算
    ├─ 输出公允价值
    ├─ 输出安全买点
    └─ 如适用，输出前瞻平台估值
    ↓
Step 5: 输出统一格式报告 → 保存为 MD 文件
```

## Step 1: 数据收集 (两阶段执行)

### 阶段架构

```
本 skill 分两阶段执行:
  Phase 1 (主会话): 数据收集 — 串行调用 mx-data/mx-search，所有数据落盘到本地文件
  Phase 2 (可 agent): 报告生成 — 只读取本地文件，不再调用任何外部 API
```

### Phase 1: 数据收集 (主会话执行，串行)

先处理输出目录，再收集数据：

```
目标目录 = {股票名}_分析数据/

如果 目标目录已存在:
    1. 将原目录整体备份为 `{股票名}_分析数据_backup_YYYYMMDD_HHMMSS/`
    2. 确认备份成功后，再创建新的 `{股票名}_分析数据/`

硬规则:
    - 所有中间产物必须保存到 `{股票名}_分析数据/`
    - 所有最终结果必须保存到 `{股票名}_分析数据/`
    - 不得将同一次分析的文件散落到其他目录
    - mx-data 输出目录参数必须指定为 `{股票名}_分析数据/`
    - mx-search 输出目录参数必须指定为 `{股票名}_分析数据/`

串行协议 (防止 429 限流):
    - mx-data 和 mx-search 调用必须串行，严禁并行
    - 每次调用之间间隔至少 3 秒
    - 同一时间只能有 1 个 mx-data 或 mx-search 请求在执行中
    - 若出现 429 错误: 等待 10 秒后重试同一查询，最多重试 2 次
    - 若重试仍失败: 跳过该数据项，在报告中标注 "数据收集受限"
```

### Phase 2: 报告生成 (只读本地文件)

```
进入 Phase 2 的前提: Step 1.5 验证门已通过
Phase 2 执行规则:
    - 只读取 {股票名}_分析数据/ 目录下已有的 mx_* 文件
    - 禁止在 Phase 2 调用 mx-data 或 mx-search
    - 所有估值数字必须能追溯到具体的 mx_* 文件
```

在 `{股票名}_分析数据/` 中收集：

| # | 数据项 | 用途 | 来源 |
|---|--------|------|------|
| 1 | 基础行情 | 当前价格、市值、PB | mx-data |
| 2 | 财务报表 | 利润、收入、ROE | mx-data |
| 3 | 收入构成 | 分部数据（转型股必需） | mx-data |
| 4 | 3年财务 | 趋势判断（**必须含毛利率、净利率、经营性现金流**） | mx-data |
| 5 | 利润质量桥接 | 归母/扣非差异来源、一次性项目 | mx-data + 财报/研报 |
| 6 | 行业数据 | 可比公司、周期位置、**竞争格局（前3名收入/增速/市占率）** | mx-search |
| 7 | 机构数据 | 目标价、评级交叉验证 | mx-search |
| 8 | 股本变动 | 近12月配股/增发/可转债转股/稀释比例 | mx-data + mx-search |
| 9 | 现金流质量 | 经营性现金流 vs 净利润趋势 | mx-data |

### 利润质量桥接（必须做）

在开始分类和估值前，必须先建立三层利润口径：

```
1. 报表归母净利润
2. 扣非归母净利润
3. 调整后经营利润（如有必要）
```

如果 `归母净利润` 与 `扣非净利润` 差异明显（经验阈值：绝对差异 > 20%，或方向相反）：

```
必须追查差异来源，并明确归类为以下哪一种：

A. 公允价值变动 / 金融资产价格波动
B. 资产减值 / 信用减值 / 存货跌价
C. 资产处置 / 出售股权 / 卖楼卖资产
D. 投资收益（权益法、处置收益、理财等）
E. 股权激励 / 一次性费用
F. 其他一次性或低频事项
```

**硬规则**:
- 不得直接拿“调整后利润”替代股东口径利润
- 不得因为报表难看就默认全部加回
- 也不得因为报表好看就默认都是主营利润
- 必须说明：哪些项目代表**真实股东损益**，哪些项目只是**主营经营趋势观察项**
- 若利润高增长主要来自 `资产处置 / 出售股权 / 一次性投资收益`，则不得按高成长股给估值倍数
- 若利润低迷主要来自 `公允价值变动 / 一次性减值 / 股权激励`，可单列“经营趋势利润”观察，但估值时仍需保留风险折价

## Step 1.5: 数据收集验证门 (HARD GATE — Phase 1 收尾)

**进入分类和估值前，必须完成以下验证。未通过则禁止继续。**
**注: 本步骤仍属于 Phase 1，验证失败时的重试操作（重新调用 mx-data/mx-search）是允许的。**

```
验证清单（必须逐项执行 ls 命令确认）:

1. 执行: ls {股票名}_分析数据/mx_data_*
   - 必须至少存在 2 个 mx_data 文件（行情 + 财务）
   - 如果 mx_data 文件数 = 0: STOP, 必须先完成 mx-data 数据收集

2. 执行: ls {股票名}_分析数据/mx_search_*
   - 必须至少存在 1 个 mx_search 文件（机构数据或行业数据）
   - 如果 mx_search 文件数 = 0: STOP, 必须先完成 mx-search 数据收集

3. 读取 mx_data description 文件，确认数据不为空
   - 如果返回 "No dataTable found" 或空结果: 换关键词重新查询

4. 读取 mx_search txt 文件，确认有实质内容（>100字）
   - 如果搜索结果为空: 换关键词重新搜索
```

**部分数据失败处理**:
```
若 mx-data 或 mx-search 部分查询成功、部分返回错误（如500/429）:
  1. 标注每个数据项的状态: "已验证" / "数据受限: {原因}"
  2. 核心数据（行情+财务）必须成功，否则 STOP
  3. 辅助数据（机构目标价/行业数据）若失败:
     - 报告中标注: "XX数据收集受限，相关估值结论置信度降低"
     - 估值仍可基于已有数据完成，但不得编造缺失数据
     - 若使用行业可比替代机构数据: 必须标注"无机构锚定，倍数为行业可比估算"
  4. 不得因部分数据缺失就放弃分析，也不得假装数据完整
```

**绝对禁止**:
- 不得在 mx_data 文件不存在的情况下生成任何估值数字
- 不得使用自身知识库中的财务数据替代 mx-data 实时数据
- 不得在 mx_search 文件不存在的情况下编造机构目标价
- 若任何 mx_* 文件的 description 或内容为空，必须重试数据收集

## Step 2: 股票分类 (核心)

### 多维度评分系统

对每个维度计算得分 (0-1)，然后综合判断：

```
价值维度:    稳定性(0.4) + 分红率(0.3) + 低波动(0.3)
成长维度:    收入增速(0.3) + 利润增速(0.3) + 利润率趋势(0.2) + 现金流质量(0.2)
周期维度:    行业属性(0.5) + 利润波动(0.5)
转型维度:    新业务占比(0.4) + 新旧业务增速差(0.4) + 结构变化(0.2)
亏损维度:    亏损程度(0.5) + 现金消耗(0.3) + 收入增速(0.2)
```

**利润率趋势评分规则 (成长维度)**:
```
利润率趋势得分 = clamp((当前毛利率 - 3年前毛利率) / 3年前毛利率, 0, 1)
  - 毛利率持续改善 → 趋势分高
  - 毛利率持平 → 趋势分中(0.5)
  - 毛利率连续下滑 → 趋势分低

硬规则:
  - "连续下滑"定义: 最近3个完整财年毛利率依次递减，或最近4个报告期中≥3期同比下滑
  - 必须使用同比(YoY)，不得使用环比(QoQ)
  - 例外: 若毛利率下降主因是高增长新业务占比提升（新业务毛利虽低但正在改善），不触发降级
  - 若收入增速>30% 但毛利率连续下滑 → 不得归类为"高质量成长股"
```

**现金流质量评分规则 (成长维度)**:
```
现金流质量得分:
  - 经营性现金流/净利润 > 1.0 且趋势改善 → 1.0
  - 经营性现金流/净利润 0.5-1.0 → 0.5
  - 经营性现金流为负（利润为正时） → 0.2
  - 两者均为负，但现金流亏损小于净利润亏损 → 0.4
```

**利润增速特殊处理 (扭亏为盈)**:
```
若基期（上一年）扣非归母净利润为负，且当期已转正:
  - 利润增速得分直接取 1.0（最高分），不得因"增速百分比无意义"而给低分
  - 不得计算理论增速百分比（如从-10亿到+5亿 = 150%）后套入常规增速分级
  - 必须在报告中标注: "扭亏为盈，利润增速得分取满分"
  - 进一步验证: 检查转正来源是否为主营改善（毛利率提升/费用率下降/收入规模效应）
    - 若主营改善 → 可支持成长股分类
    - 若主要来自一次性项目 → 按利润质量桥接规则处理，不得直接给满分

若基期为负且当期仍为负（亏损收窄）:
  - 利润增速得分 = clamp(亏损收窄幅度 / 100, 0, 0.7)
  - 不取满分，因为尚未真正盈利
  - 例如: 从-10亿收窄到-5亿 → 收窄50% → 得分 0.5

若基期为正且当期转负（由盈转亏）:
  - 利润增速得分 = 0.1（最低档）
  - 不得因前几年利润为正就给中间分数
  - 分类时需额外评估: 是一次性亏损还是趋势性恶化
  - 若一次性因素导致（如大幅计提减值/一次性投入）:
    - 可在报告中说明"经营趋势仍可观察"，但分类得分不变
  - 若经营性亏损（收入增速不达预期/毛利率持续下滑/费用失控）:
    - 不得归类为"成长股"
    - 建议归入"转型早期"或"困境股"
```

**分类口径硬规则**:
```
1. 分类阶段的"利润增速"默认优先看 扣非归母净利润增速
2. 若扣非也明显失真（经验阈值: 与报表归母差异>20%，或方向相反）:
   - 可用"调整后经营利润"仅辅助判断主营趋势
   - 但不得直接据此给高成长估值倍数
3. 若高增长主要来自 资产处置 / 出售股权 / 一次性投资收益 / 公允价值抬升:
   - 不得直接分类为"高成长股"
   - 替代路径: 降级为"普通增长股"，PEG倍数降一档
4. 若报表利润偏弱主要来自 公允价值下跌 / 一次性减值 / 股权激励:
   - 可保留"成长/转型候选"判断
   - 但报告中必须提示: 股东口径利润仍承压，估值要保留风险折价
5. 最终必须明确:
   - 哪个利润口径用于分类
   - 哪个利润口径用于估值主锚
   - 哪个利润口径仅用于观察经营趋势
```

**公司治理风险检查 (所有类型适用)**:
```
进入分类前，必须检查过去12个月是否发生:
□ 实控人/董事长/CFO变更
□ 已公告但未执行的变更计划

若发生变更，进一步判断:
1. 变更人是关联交易核心方?
   - 是 → 不得归为"短期情绪影响"
   - 必须评估对以下的影响: 关联交易协议持续性、战略支持可靠性、关系溢价
   - 估值影响: 执行风险折扣额外+3-5%
2. 变更类型分类:
   - 国企正常组织调动 → 标注"常规"，不触发折扣
   - 继承/家族内部 → 标注"关注接班能力"
   - 恶意收购/控制权争夺 → 标注"高风险"，触发治理折扣+5%
   - 被动变更（质押爆仓等）→ 标注"高风险"，触发治理折扣+5%
3. 数据不可获取时:
   - 标注"治理评估受限"
   - 估值时默认增加3%透明度折价
```

### 分类决策规则

| 分类 | 判定条件 | 估值方法 |
|------|----------|----------|
| **价值股** | 价值分最高，且扣非口径增速<15%，ROE>10% | 方法1: PE/PB/股息率 |
| **成长股** | 成长分最高，且扣非/经营趋势增速>30%，并通过利润质量桥接 | 方法2: PEG/Forward PE/DCF |
| **周期股** | 周期分最高，且行业为周期行业 | 方法3: 正常化PE/PB |
| **转型股** | 转型分>0.6，且新旧业务均明显 | 方法4: SOTP分部估值 |
| **亏损股** | 扣非归母净利润<0，且收入增速>50% | 方法5: PS/终局估值 |
| **困境股 / 低增速亏损股** | 扣非归母净利润<0，且收入增速<=50% | 资产价值/PB/等待拐点 |
| **困境股 / 利润暴跌仍盈利** | 利润较正常水平下滑>50%，全年仍盈利 | 方法6: PB主锚 + 正常化PE辅助 |

**边界缓冲处理**:
- 扣非/经营趋势增速28-32%区间 → 提示"接近成长股阈值，需人工确认是按15-30%过渡区处理，还是按成长股处理"
- 转型分0.55-0.65 + 新业务18-22% → 提示"转型早期，谨慎使用SOTP；若重大并表已明显改变盈利结构，可按转型股双轨估值处理"

**15%端点规则**:
```
若 扣非/经营趋势利润增速恰好约等于15%（如 14.5%-15.5%）:
    - 不默认直接归入价值股
    - 先进入"15-30%过渡区"规则处理
    - 只有在ROE、分红、稳定性都明显更像成熟价值股时，才可按方法1为主
```

**重大并表 / pro forma 规则**:
```
如果 过去12个月内完成重大收购、并表或资产重组，且新增资产满足任一条件:
    - 新增资产收入/EBITDA占合并口径 > 30%
    - 新增资产估值占总估值 > 30%
    - 次年利润预测较当前报表口径抬升 > 50%

则:
    1. 分类结果必须额外标记 "成长+转型候选"
    2. 估值必须双轨输出:
       - 静态公允价值: SOTP / 分部估值
       - 前瞻平台估值: Forward PE / PEG / EV
    3. 与机构目标价对比时，默认先对比"公允价值"或"前瞻平台估值"
       不得拿"安全买点"直接对比机构目标价
```

**增速15-30%区间处理** (价值与成长之间的过渡区):
```
如果 扣非/经营趋势利润增速在15-30%区间:
    先检查利润质量桥接，确认增长是否来自主营
    如果 ROE > 12% 且 分红率 > 30%:
        → "高质量成长股，偏价值属性"
        → 使用PEG估值 (基准PE 15-25x)
    否则如果 利润稳定性高(5年波动<20%):
        → "稳健增长股"
        → PE Band为主 (12-18x)，PEG为辅验证
    否则:
        → "普通增长股"
        → PEG估值 (1.0-1.2x)
```

**无法分类兜底**:
```
如果 所有维度得分 < 0.3:
    返回 "数据不足，无法可靠分类"
    建议: "请检查财务数据完整性，或在本 skill 内按报告模板进行人工分析"
```

### 混合类型处理

如果前两名得分差距 < 0.15，识别为混合类型：

| 混合类型 | 权重分配 | 理由 |
|----------|----------|------|
| 周期+转型 | 周期40% + SOTP 60% | 周期影响短期盈利，转型决定长期价值 |
| 成长+转型 | SOTP 50% + Forward PE/PEG 50% | 并表前后口径差异大时，必须同时保留资产价值与前瞻盈利视角 |
| 价值+周期 | 正常化PE 70% + PB 30% | 周期位置决定入场时机，价值属性决定长期持有 |
| 成长+周期 | 周期位置优先 | 高波动环境，先判断周期位置再论成长 |

**三重混合处理**: 输出"复杂类型，建议人工介入分步分析"

**成长+周期处理硬规则**:
```
若识别为 成长+周期:
    1. 先判断周期位置，再决定是否允许使用成长股倍数
    2. 若处于周期顶部或利润显著高于正常化水平:
       - 禁用高PEG / 高Forward PE 作为主锚
       - 默认使用正常化PE / PB
    3. 若处于周期底部或复苏早期，且成长逻辑来自真实市占率提升/产品升级:
       - 可将 PEG / Forward PE 作为辅助验证
       - 但主结论仍以周期位置校准后的利润口径为准
    4. 报告中必须说明:
       - 当前使用的是报表利润、正常化利润，还是 next-year 利润
       - 成长逻辑是否可能只是周期回升而非结构性成长
```

**双轨输出硬规则**:
```
若 SOTP公允价值 与 前瞻平台估值 差异 > 2x:
    - 不得简单取平均后输出单一目标价
    - 必须并列展示:
      1. 静态公允价值区间
      2. 前瞻平台估值区间
      3. 安全买点区间
    - 必须解释差异来自 分部价值 / 并表协同 / 利润口径 / 估值倍数 的哪几项
```

## Step 3: 估值方法执行

### 数据一致性校验 (硬规则 — 估值前必须执行)

```
在执行任何估值计算前，必须对所有关键数据进行交叉验证:

1. 增速与绝对数一致性:
   误差 = |实际值 - 基期×(1+增速%)| / |基期×(1+增速%)|
   - 收入数据: 误差阈值 3%
   - 利润数据: 误差阈值 5%
   - 前瞻预测: 误差阈值 10%
   - 若超过阈值: 必须标注"数据来源不一致"并说明差异原因

2. 负基数豁免:
   若基期为负值（如亏损期的净利润）:
   - 不得使用增速交叉验证
   - 改为绝对数变动方向检查（亏损收窄/扩大）

3. 口径一致性检查:
   若同一报告期内发生: 会计准则变更、重大收购/剥离、汇率影响>5%
   → 增速与绝对数交叉验证不适用，必须标注"口径不可比"

4. 来源混用禁止:
   - 不得同时使用来源A的增速和来源B的绝对数而不标注差异
   - 若不同来源数据矛盾: 以 mx-data 实际数据为准，mx-search 研报数据作为辅助验证
```

根据分类结果，执行对应估值方法（详见docs/目录参考文档）：

### 方法1: 价值股估值

**适用**: 利润低增长或平稳增长（通常0-15%），稳定分红，成熟行业

**核心公式**:
```
目标价 = EPS × PE倍数
PE倍数 = 历史PE中枢 (通常8-15x)

或

目标价 = BPS × PB倍数
PB倍数 = ROE × 质量系数 (1.0-1.5)

或 (高分红股)

目标价 = 每股股息 / 目标股息率 (通常3-5%)
```

**输出**: 保守/中性/乐观三档目标价

---

### 方法2: 成长股估值

**适用**: 扣非/经营趋势利润增速>30%，可预测性强

**扭亏为盈估值规则** (基期为负、当期刚转正):
```
若公司刚从亏损转为盈利（基期扣非归母净利润<0，当期>0）:
  1. PEG 不适用（利润增速百分比无意义）→ 禁用 PEG 作为主锚
  2. 估值主锚 = Forward PE（基于机构一致预期的次年利润）
     - 必须来自 mx-search 机构预测
     - 必须说明: Forward EPS 是扣非口径还是报表口径
  3. 辅助验证:
     - 收入PS估值作为上限参考
     - 可比公司PE作为倍数校准
  4. 三档情景:
     - 保守: 机构预测下限 × 可比PE下半区
     - 中性: 机构预测中值 × 可比PE中间区
     - 乐观: 机构预测上限 × 可比PE上半区
  5. 必须标注: "首年盈利，历史PE无参考意义，Forward PE为唯一主锚"
  6. 风险提示: 首年盈利可能不稳定，安全边际建议25-30%（高于常规的15-25%）
```

**前置检查**:
```
1. 先确认高增长是否来自主营，而不是资产处置、公允价值收益、一次性投资收益
2. 若报表归母、扣非、调整后经营利润三者差异明显:
   - 分类优先看扣非/经营趋势
   - 估值主锚优先看可持续利润口径
3. 若报表归母仍显著受真实股东损失拖累:
   - 可保留成长判断
   - 但Forward PE / PEG倍数需保留折价，不得直接套行业最高估值
```

**核心公式**:
```
PEG方法:
合理PE = 利润增长率 × PEG目标 (1.0-1.5)
目标价 = EPS × 合理PE

Forward PE:
目标价 = Forward EPS × 目标PE (25-50x)

DCF:
企业价值 = Σ(FCFt/(1+r)^t) + 终值/(1+r)^n
```

**PEG 与 Forward PE 优先级规则**:
```
1. 普通成长股默认先用 PEG 定锚:
   - PEG负责把"增长率"映射成基准PE
   - 这是成长股的主估值口径
2. Forward PE 仅在以下条件满足时用于 next-year 交叉验证:
   - next-year EPS / 净利润口径清晰
   - 已说明是否扣非、是否稀释、是否含一次性项目
   - 有可比公司或机构一致预期作为倍数参考
3. 若 PEG 推导PE 与 Forward PE 对应估值冲突明显（经验阈值: >20%）:
   - 默认取更保守的一侧作为主结论
   - 另一侧作为补充情景列示
   - 报告中必须解释冲突来自 增速年份 / 利润口径 / 倍数体系 的哪一项
4. 不得同时拿 PEG 的高端区间 和 Forward PE 的高端区间 叠加拔高估值
```

**增速分级**:
- >50%: PEG 1.0-1.3 (默认1.0), PE 50-70x
- 30-50%: PEG 0.8-1.1 (默认0.9), PE 30-50x
- 15-30%: PEG 0.6-1.0 (默认0.8), PE 15-30x — **但此区间必须优先遵循"增速15-30%区间处理"规则，本表仅为 PEG 参数参考**

**PEG 取值规则**:
```
1. 默认取区间中值，不得无理由取高端
2. 若取区间高端，必须在报告中说明理由（如: 行业景气度/竞争优势/机构一致溢价）
3. 三档情景必须使用不同 PEG: 保守取低/中性取中/乐观取高
4. 不得三档都取同一 PEG 然后只调 EPS
5. 恢复性增长 PEG 修正:
   - 若当前高增速(>30%)前有1+年利润下滑 → 属"恢复性增长"
   - PEG默认取区间下半区（如30-50%档: PEG 0.7-0.9而非0.8-1.1）
   - 不得按"持续高增长"取PEG高端
   - 必须在报告中标注: "恢复性增长，PEG已做保守调整"
```

**前瞻利润/EPS 硬规则 (禁止自行估算)**:
```
1. Forward EPS / Forward 净利润 必须来自 mx-search 机构一致预期
   - 优先搜索 "{股票名}机构目标价 业绩预测 盈利预测" 获取
   - 必须在报告中注明: Forward 数据来自哪家机构

2. 禁止以下行为:
   - 禁止自行假设 "2026E利润恢复到XX亿" 后直接用于估值
   - 禁止使用 "基于行业平均增速推算" 等自创前瞻数字
   - 禁止在没有机构预测支撑的情况下给出 Forward PE 估值

3. 如果 mx-search 未返回有效的机构前瞻数据:
   - 只能使用 mx-data 获取的历史数据进行估值（TTM 口径）
   - 报告中必须标注: "前瞻估值缺失，本报告仅基于历史数据"
   - 不得用 "行业可比" 或 "合理假设" 替代机构一致预期

4. Forward 倍数必须基于机构研报锚定:
   - 必须引用 mx-search 返回的具体研报 PE/PEG 倍数
   - 不得自行设定 PEG 范围然后随意取值
```

### 方法3: 周期股估值

**适用**: 大宗商品、航运、建筑、化工

**关键**: 先判断周期位置

| 周期位置 | 主方法 | 估值逻辑 |
|----------|--------|----------|
| 底部 | PB | 市值 < 重置成本，安全边际 |
| 正常 | 正常化PE | 5-7年平均利润 × 12x |
| 顶部 | 正常化PE+逃顶 | 利润高点不可持续，提前减仓 |

**警示**: 周期顶部PE最低（危险），底部PE最高或为负（机会）

### 方法4: 转型股估值 (SOTP)

**适用**: 新业务20-50%，旧业务衰退

**核心公式**:
```
公允价值 = Σ(分部估值) × (1 - 执行风险折扣)
安全买点 = 公允价值 × (1 - 安全边际)

步骤:
1. 识别各业务分部
2. 为每个分部选估值方法 (成熟→PE, 成长→PS/PE, 亏损→PB)
3. 计算各分部估值
4. 加总 = SOTP毛估值
5. 应用执行风险折扣 (见下方分级规则) → 得到公允价值
6. 应用安全边际 (15-25%) → 得到安全买点
7. 如存在重大并表 / pro forma 场景，再追加 Forward PE / PEG / EV 交叉验证
```

**执行风险折扣分级规则 (替代简单百分比区间)**:
```
折扣 = 转型阶段基数 + Σ(风险项权重) - Σ(安全项抵消)

转型阶段基数:
  - 早期转型（新业务<15%）: 基数 10%
  - 中期转型（新业务15-40%）: 基数 5%
  - 晚期转型（新业务>40%）: 基数 0%

风险项（累加）:
  致命风险 (每项+6%):
    □ 公司仍在报表亏损（扣非口径）
    □ 单一客户收入占比>30%
    □ 核心管理层变更且变更人为关联交易核心方

  重大风险 (每项+4%):
    □ 新业务毛利率<旧业务且无改善趋势
    □ 需持续融资/配售支撑扩张（且非战略投资型增发）
    □ 竞争对手收入规模>自身5倍

  一般风险 (每项+2%):
    □ 非核心管理层变动
    □ 客户集中度20-30%
    □ 基础设施投入期导致短期毛利承压（需注明投入期预计时长）

安全项（抵消，每项-2%）:
    □ 新业务已贡献正EBITDA
    □ 客户多元（前5客户合计<40%）
    □ 核心管理层稳定（核心团队任职>3年）
    □ 现金储备>24个月运营支出
    □ 历史预测与实际偏差<20%

上限: 40%（不含安全项抵消后的净值）
下限: 转型阶段基数（安全项抵消不使折扣低于阶段基数）

相关性调整:
  若"亏损"+"需融资"同时触发 → 不额外加算，只取两项中较高者
  （因为亏损几乎必然导致融资需求，属同一风险源）

硬性否决:
  若风险项触发≥5个 → 额外标注"高风险，建议人工介入"
```

**简化结构示例** (转型股 / 重大并表场景):
```
成熟业务 + 成长业务 + 并表资产 = SOTP毛估值
应用执行风险折扣(按阶段判断) → 得到公允价值
再按总股本换算 → 得到每股公允价值
若再施加安全边际 → 得到安全买点

若公司已完成重大并表，且次年利润/EBITDA显著跃升:
再补一套 Forward PE / PEG / EV/EBITDA
→ 得到前瞻平台估值

结论:
1. 安全买点 != 机构目标价
2. 机构通常对比的是公允价值或前瞻平台估值
3. 重大并表或成长+转型案例必须同时展示 SOTP 与 Forward PE/PEG，不能只保留单一保守口径
```

**详细计算步骤** (见 docs/method-transformation.md):
包含分部利润估算、费用分摊、所得税调整、执行风险折扣应用等完整流程。

**股本稀释调整规则 (所有估值方法适用)**:
```
硬规则:
1. 近12个月内的股本变动必须收集: 配股/增发/可转债转股/期权行权
2. 同时检查已公告但未执行的增发/转股计划
3. 所有"每股"指标必须基于最新总股本（含已完成的配售/增发）
4. 若存在可转债且转股价<正股价130%，应使用完全稀释股本计算

稀释披露规则:
  - 近12个月稀释 3-5%: 在报告中标注稀释比例
  - 近12个月稀释 5-15%: 必须列出稀释前后每股估值对比
  - 近12个月稀释 >15%: 估值结论需额外风险折价+3%
  - 3年累计稀释>15%（即使单年<5%）: 须标注"长期稀释风险"

稀释质量评估:
  - 好的稀释: 以接近市价或溢价增发，用于战略收购/产能扩张 → 标注但不打折
  - 中性稀释: 以折扣价增发，用于一般用途 → 标注+每股估值按稀释后计算
  - 差的稀释: 大幅折价增发/低价行权，用于还债/输血 → 标注+额外折价+3%
```

### 方法5: 亏损股估值

**适用**: 当前亏损但高增长 (收入增速>50%)

**核心公式**:
```
PS方法:
市值 = 收入 × PS倍数 (5-25x，视增速而定)

终局估值:
稳态市值 = TAM × 市占率 × 利润率 × PE
现值 = 稳态市值 / (1+折现率)^年数
```

**风险检查**:
- 现金runway必须>12个月
- 收入质量（经常性收入占比）
- 盈利路径可见性

**不适用场景**:
```
若 当前亏损 且 收入增速<=50%:
    - 不应继续使用PS/终局估值作为主方法
    - 默认归入"困境股 / 低增速亏损股"
    - 优先看 PB / 净资产 / 资产价值 / 现金消耗
    - 结论以"等待盈利拐点"或"仅适合深度价值/重组博弈"表述
    - 亏损判断默认优先看扣非归母净利润；若扣非失真，再补充说明报表归母与经营趋势口径
```

### 方法6: 困境股估值（利润暴跌但仍盈利）

**适用**: 全年仍盈利但利润较正常水平大幅下滑（>50%），收入萎缩或停滞

**PE与PB冲突处理规则**:
```
若 当前PE极高（>50x）但PB处于合理区间（1-4x）:
  1. 判断PE高是因为利润临时低迷还是结构性恶化:
     - 临时低迷（一次性因素/合同确认节奏/行业周期底部）→ PB为主锚，PE仅作参考
     - 结构性恶化（收入持续萎缩/市场份额丢失）→ PB仍为主锚，但需额外折价
  2. 不得因PE极高就默认"估值泡沫"，也不得忽视利润恶化的现实
  3. 正常化PE可用于参考: 取过去3-5年平均利润 × 合理PE → 对比当前市值
  4. 若PB公允价值与正常化PE公允价值差异 > 50%:
     - 并列展示两个估值
     - 说明差异来源（利润临时低迷 vs 资产高估）
     - 不得简单取平均
```

**核心公式**:
```
PB估值（主锚）:
目标价 = BPS × PB倍数
PB倍数 = 行业可比PB × 质量调整系数

正常化PE（辅助验证）:
目标价 = 正常化EPS × 合理PE（15-25x）
正常化EPS = 过去3-5年平均利润 / 总股本

安全买点 = 综合公允价值 × (1 - 安全边际30%)
注: 困境股安全边际默认30%，高于常规的15-25%
```

**困境股风险检查清单**:
```
□ 收入是否连续2+年萎缩 → 是: 估值需额外折价+5%
□ 利润下滑是否来自主营（非一次性） → 是: 需等待恢复信号
□ 现金流是否为负 → 是: PB估值需保留流动性折价
□ 行业是否处于政策周期底部 → 是: 可适当乐观
□ 是否有央企/国企背景（安全垫） → 是: PB倍数可取上半区
□ 资产负债率是否健康（<40%） → 是: 资产价值有支撑
```

## Step 4: 交叉验证

### 方法内验证
- PE vs PB 差异是否在±30%内
- DCF假设是否合理（增长率、折现率）
- 归母/扣非/调整后经营利润三者是否已分层说明
- 高增长利润是否来自主营，还是来自资产处置/投资收益/公允价值波动

### 竞争折价规则 (转型股/成长股/亏损股适用)
```
1. 行业口径要求:
   - 必须明确写出行业口径（如"中国公有云IaaS"而非"云计算"）
   - 可比公司至少3家必须在同一子行业

2. 规模劣势调整:
   - 公司收入 < 龙头的1/6 → 估值倍数取可比区间下半区
   - 公司收入介于龙头的1/6到1/4 → 估值倍数取可比区间中间区
   - 公司收入 > 龙头的1/4 → 可使用可比区间上半区

3. 增速修正:
   若目标公司增速 > 龙头增速1.5x → 可上调一个倍数区间
   （如从"下半区"上调到"中间区"），但必须在报告中说明理由

4. 客户集中度折价:
   - 单一客户占比20-30%: 已在执行风险折扣中计入（一般风险+2%）
   - 单一客户占比30-50%: 已在执行风险折扣中计入（致命风险+6%）
   - 单一客户占比>50%: 额外标注"极高风险依赖"，执行风险折扣额外+3%
   注意: 此处折扣与Step 3执行风险折扣中的客户集中度风险项合并计算，不叠加

5. 护城河评估:
   必须在报告中说明公司的差异化竞争力（技术壁垒/生态绑定/品牌/成本优势）
   若无法给出至少一项可持续的差异化优势 → 不得使用行业平均或以上倍数
```

### 与机构对比
- 必须先列清三种口径: 公允价值 / 前瞻平台估值 / 安全买点

- 若公允价值与前瞻平台估值同时存在:
  - 先判断机构研报主口径是分部/NAV还是 next-year PE/PEG/EV

  - 不能判断时，默认先展示公允价值，再补展示平台估值
  - 不得为了贴近机构目标价临时挑选更高的一侧做 headline
- 如果差异>30%，分析原因（假设差异、方法差异）

### 与历史估值对比
- 当前PE/PB处于历史什么分位
- 是否显著高于/低于历史中枢

## 估值方法快速参考

| 股票类型 | 核心指标 | 估值锚定 | 典型倍数 |
|----------|----------|----------|----------|
| 价值股 | ROE、股息率 | 历史PE/PB中枢 | PE 8-15x, PB 1-2x |
| 成长股 | 扣非/经营趋势增速 | PEG分档 + Forward交叉验证 | 先看详细规则，不直接套单一区间 |
| 周期股 | 周期位置 | 正常化利润 | PE 10-15x, PB 0.8-1.5x |
| 转型股 | 分部利润 + 前瞻利润 | SOTP + Forward交叉验证 | 分部不同 |
| 亏损股 | 收入增速 | PS | PS 5-25x |

**口径提醒**:
- 全公司价值股的 `PE 8-15x` 是历史中枢口径，适用于整家公司成熟稳定估值
- SOTP 里的成熟分部 `PE 15-25x` 是分部可比口径，适用于拆分估值，不得直接拿来替代整家公司价值股中枢
- 成长股快速参考只作索引，具体倍数以 `方法2` 里的 PEG 分档、Forward PE 优先级和利润质量约束为准

## 重要提醒

### 估值不是精确科学
- 所有估值都是"大概正确"
- 关键是逻辑自洽，不是数字精确
- 安全边际比精确估值更重要

### 动态调整
- 季度财报后重新评估
- 行业重大变化后重新评估
- 催化剂兑现/落空后重新评估

### 分类纠错

当自动分类明显错误时，用户可手动指定类型：

```text
# 在指令中直接说明希望采用的估值类型
/stock-analysis-unified 股票名，按价值股处理
/stock-analysis-unified 股票名，按成长股处理
/stock-analysis-unified 股票名，按周期股处理
/stock-analysis-unified 股票名，按转型股处理
/stock-analysis-unified 股票名，按亏损股处理
```

**常见分类错误信号**:
- 增速30%的公司被分为价值股 → 检查利润稳定性
- 明显周期股被分为成长股 → 检查利润波动率
- 转型早期被识别为转型成功 → 检查新业务占比

### 风险控制
- 单股仓位不超过10%
- 设置止损，严格执行
- 不追逐过高估值

## 错误处理

### 数据不足处理

```
如果 mx-data 返回空数据:
    1. 检查股票代码是否正确
    2. 尝试使用拼音或别名搜索
    3. 如仍失败，提示:"该股票数据暂不可用，请稍后重试"
```

### 分类失败处理

```
如果 所有维度得分 < 0.3:
    返回: "⚠️ 无法可靠分类"
    建议: 
    - 检查财务数据完整性
    - 按本 skill 的统一报告模板进行人工分析
    - 或在指令中明确说明希望按价值股/成长股/周期股/转型股/亏损股处理
```

### 边界情况提示

| 情况 | 提示信息 | 建议操作 |
|------|----------|----------|
| 增速15-18% | "处于15-30%过渡区，建议人工确认" | 查看ROE、分红率和利润稳定性，决定偏价值还是偏成长 |
| 新业务18-22% | "转型早期，谨慎使用SOTP" | 降低执行风险折扣至25-30% |
| 周期顶部信号 | "当前PE处于历史低位，可能是周期顶部" | 优先使用正常化PE，降低仓位 |
| 亏损但增速<50% | "亏损股但增速不足，不符合终局估值条件" | 使用PB估值，等待盈利拐点 |
