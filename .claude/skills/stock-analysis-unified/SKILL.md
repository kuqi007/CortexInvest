# 股票统一分析系统 (Unified Stock Analysis)

> **设计理念**: 一个入口，智能分类，自动匹配最优估值方法

---

## 使用方式

```bash
# 统一入口，自动识别股票类型并匹配估值方法
/stock-analysis-unified 东阳光
/stock-analysis-unified 潍柴动力
/stock-analysis-unified 宁德时代
```

---

## 工作流程

```
用户输入股票名
    ↓
Step 1: 数据收集 (mx-data + mx-search)
    ↓
Step 2: 智能分类 (多维度评分)
    ↓
Step 3: 匹配估值方法 (主方法 + 条件触发双轨)
    ├─ 价值股 → PE/PB/股息率
    ├─ 成长股 → PEG/Forward PE/DCF
    ├─ 周期股 → 正常化PE/PB
    ├─ 转型股 → SOTP
    │   └─ 若重大并表 / pro forma → 追加 Forward PE/PEG/EV
    └─ 亏损股 → PS/终局估值
    ↓
Step 4: 执行估值计算
    ├─ 输出公允价值
    ├─ 输出安全买点
    └─ 如适用，输出前瞻平台估值
    ↓
Step 5: 输出统一格式报告 → 保存为 MD 文件
```

## Step 2: 股票分类 (核心)

### 多维度评分系统

对每个维度计算得分 (0-1)，然后综合判断：

```
价值维度:    稳定性(0.4) + 分红率(0.3) + 低波动(0.3)
成长维度:    收入增速(0.4) + 利润增速(0.4) + 质量(0.2)
周期维度:    行业属性(0.5) + 利润波动(0.5)
转型维度:    新业务占比(0.4) + 新旧业务增速差(0.4) + 结构变化(0.2)
亏损维度:    亏损程度(0.5) + 现金消耗(0.3) + 收入增速(0.2)
```

### 分类决策规则

| 分类 | 判定条件 | 估值方法 |
|------|----------|----------|
| **价值股** | 价值分最高，且增速<15%，ROE>10% | 方法1: PE/PB/股息率 |
| **成长股** | 成长分最高，且增速>30%，利润>0 | 方法2: PEG/Forward PE/DCF |
| **周期股** | 周期分最高，且行业为周期行业 | 方法3: 正常化PE/PB |
| **转型股** | 转型分>0.6，且新旧业务均明显 | 方法4: SOTP分部估值 |
| **亏损股** | 利润<0，收入增速>50% | 方法5: PS/终局估值 |

**边界缓冲处理**:
- 增速28-32%区间 → 提示"可能为价值或成长，需人工确认"
- 转型分0.55-0.65 + 新业务18-22% → 提示"转型早期，谨慎使用SOTP"

**重大并表 / pro forma 规则**:
```
如果 过去12个月内完成重大收购、并表或资产重组，且新增资产满足任一条件:
    - 新增资产收入/EBITDA占合并口径 > 30%
    - 新增资产估值占总估值 > 30%
    - 次年利润预测较当前报表口径抬升 > 50%

则:
    1. 分类结果必须额外标记 "成长+转型候选"
    2. 估值必须双轨输出:
       - 静态公允价值: SOTP / 分部估值
       - 前瞻平台估值: Forward PE / PEG / EV
    3. 与机构目标价对比时，默认先对比"公允价值"或"前瞻平台估值"
       不得拿"安全买点"直接对比机构目标价
```

**增速15-30%区间处理** (价值与成长之间的过渡区):
```
如果 利润增速在15-30%区间:
    如果 ROE > 12% 且 分红率 > 30%:
        → "高质量成长股，偏价值属性"
        → 使用PEG估值 (基准PE 15-25x)
    否则如果 利润稳定性高(5年波动<20%):
        → "稳健增长股"
        → PE Band为主 (12-18x)，PEG为辅验证
    否则:
        → "普通增长股"
        → PEG估值 (1.0-1.2x)
```

**无法分类兜底**:
```
如果 所有维度得分 < 0.3:
    返回 "数据不足，无法可靠分类"
    建议: "请检查财务数据完整性，或使用 /stock-fundamental-analysis 进行人工分析"
```

### 混合类型处理

如果前两名得分差距 < 0.15，识别为混合类型：

| 混合类型 | 权重分配 | 理由 |
|----------|----------|------|
| 周期+转型 | 周期40% + SOTP 60% | 周期影响短期盈利，转型决定长期价值 |
| 成长+转型 | SOTP 50% + Forward PE/PEG 50% | 并表前后口径差异大时，必须同时保留资产价值与前瞻盈利视角 |
| 价值+周期 | 正常化PE 70% + PB 30% | 周期位置决定入场时机，价值属性决定长期持有 |
| 成长+周期 | 周期位置优先 | 高波动环境，先判断周期位置再论成长 |

**三重混合处理**: 输出"复杂类型，建议人工介入分步分析"

## Step 3: 估值方法执行

根据分类结果，执行对应估值方法（详见docs/目录参考文档）：

### 方法1: 价值股估值

**适用**: 利润增速5-15%，稳定分红，成熟行业

**核心公式**:
```
目标价 = EPS × PE倍数
PE倍数 = 历史PE中枢 (通常8-15x)

或

目标价 = BPS × PB倍数
PB倍数 = ROE × 质量系数 (1.0-1.5)

或 (高分红股)

目标价 = 每股股息 / 目标股息率 (通常3-5%)
```

**输出**: 保守/中性/乐观三档目标价

---

### 方法2: 成长股估值

**适用**: 利润增速>30%，可预测性强

**核心公式**:
```
PEG方法:
合理PE = 利润增长率 × PEG目标 (1.0-1.5)
目标价 = EPS × 合理PE

Forward PE:
目标价 = Forward EPS × 目标PE (25-50x)

DCF:
企业价值 = Σ(FCFt/(1+r)^t) + 终值/(1+r)^n
```

**增速分级**:
- >50%: PEG 1.0-1.5, PE 50-80x
- 30-50%: PEG 0.8-1.2, PE 30-50x

---

### 方法3: 周期股估值

**适用**: 大宗商品、航运、建筑、化工

**关键**: 先判断周期位置

| 周期位置 | 主方法 | 估值逻辑 |
|----------|--------|----------|
| 底部 | PB | 市值 < 重置成本，安全边际 |
| 正常 | 正常化PE | 5-7年平均利润 × 12x |
| 顶部 | 正常化PE+逃顶 | 利润高点不可持续，提前减仓 |

**警示**: 周期顶部PE最低（危险），底部PE最高或为负（机会）

---

### 方法4: 转型股估值 (SOTP)

**适用**: 新业务20-50%，旧业务衰退

**核心公式**:
```
公允价值 = Σ(分部估值) × (1 - 执行风险折扣)
安全买点 = 公允价值 × (1 - 安全边际)

步骤:
1. 识别各业务分部
2. 为每个分部选估值方法 (成熟→PE, 成长→PS/PE, 亏损→PB)
3. 计算各分部估值
4. 加总 = SOTP毛估值
5. 应用执行风险折扣 (15-35%，根据转型阶段) → 得到公允价值
6. 应用安全边际 (15-25%) → 得到安全买点
7. 如存在重大并表 / pro forma 场景，再追加 Forward PE / PEG / EV 交叉验证
```

**简化示例** (东阳光，快速估算):
```
传统业务 + 电子材料 + 算力资产 = SOTP毛估值 500-700亿
执行风险-10%至-20%后 → 公允价值约 450-560亿
按30.1亿股计算 → 公允价值约 15-19元/股
若再施加安全边际-15%至-20% → 安全买点约 12-16元/股

若公司已完成重大并表，且2026E利润预测跃升至18-20亿:
Forward PE 50-60x → 前瞻平台估值约 900-1200亿
对应平台估值约 30-40元/股

结论:
1. 安全买点 != 机构目标价
2. 机构通常对比的是公允价值或前瞻平台估值
3. 东阳光这类案例必须同时展示 SOTP 与 Forward PE/PEG，不能只保留单一保守口径
```

**详细计算步骤** (见 docs/method-transformation.md):
包含分部利润估算、费用分摊、所得税调整、执行风险折扣应用等完整流程。

---

### 方法5: 亏损股估值

**适用**: 当前亏损但高增长 (收入增速>50%)

**核心公式**:
```
PS方法:
市值 = 收入 × PS倍数 (5-25x，视增速而定)

终局估值:
稳态市值 = TAM × 市占率 × 利润率 × PE
现值 = 稳态市值 / (1+折现率)^年数
```

**风险检查**:
- 现金runway必须>12个月
- 收入质量（经常性收入占比）
- 盈利路径可见性

---

## Step 4: 交叉验证

### 方法内验证
- PE vs PB 差异是否在±30%内
- DCF假设是否合理（增长率、折现率）

### 与机构对比
- 必须先明确对比口径: 公允价值 / 前瞻平台估值 / 安全买点
- 默认使用"公允价值"或"前瞻平台估值"对比机构一致目标价
- 安全买点仅用于建仓区间，不作为机构目标价对比口径
- 如果差异>30%，分析原因（假设差异、方法差异）

### 与历史估值对比
- 当前PE/PB处于历史什么分位
- 是否显著高于/低于历史中枢

## 重要提醒

### 估值不是精确科学
- 所有估值都是"大概正确"
- 关键是逻辑自洽，不是数字精确
- 安全边际比精确估值更重要

### 动态调整
- 季度财报后重新评估
- 行业重大变化后重新评估
- 催化剂兑现/落空后重新评估

### 分类纠错

当自动分类明显错误时，用户可手动指定类型：

```bash
# 强制使用特定估值方法
/stock-analysis-unified 股票名 --type=value    # 强制价值股估值
/stock-analysis-unified 股票名 --type=growth   # 强制成长股估值
/stock-analysis-unified 股票名 --type=cyclical # 强制周期股估值
/stock-analysis-unified 股票名 --type=trans    # 强制SOTP估值
/stock-analysis-unified 股票名 --type=loss     # 强制亏损股估值
```

**常见分类错误信号**:
- 增速30%的公司被分为价值股 → 检查利润稳定性
- 明显周期股被分为成长股 → 检查利润波动率
- 转型早期被识别为转型成功 → 检查新业务占比

### 风险控制
- 单股仓位不超过10%
- 设置止损，严格执行
- 不追逐过高估值

### 示例2: 分析转型股（东阳光）

```bash
/stock-analysis-unified 东阳光
```

**关键步骤**:
1. 识别公司属于"成长+转型候选": 传统业务仍贡献利润，但秦淮数据并表将显著改变 2026E 盈利结构
2. 先做静态 SOTP: 拆分制冷剂、电子元器件、铝箔、算力资产、液冷/机器人等分部，得到毛估值与公允价值

4. 单独列示三层价格: 公允价值、平台估值、安全买点
5. 与机构目标价对比时，优先使用公允价值或平台估值，不得用安全买点直接比较

## 错误处理

### 数据不足处理

```
如果 mx-data 返回空数据:
    1. 检查股票代码是否正确
    2. 尝试使用拼音或别名搜索
    3. 如仍失败，提示:"该股票数据暂不可用，请稍后重试"
```

### 分类失败处理

```
如果 所有维度得分 < 0.3:
    返回: "⚠️ 无法可靠分类"
    建议: 
    - 检查财务数据完整性
    - 使用 /stock-fundamental-analysis 进行人工分析
    - 或手动指定类型: --type=value/growth/cyclical/trans/loss
```

### 边界情况提示

| 情况 | 提示信息 | 建议操作 |
|------|----------|----------|
| 增速15-18% | "处于价值/成长边界，建议人工确认" | 查看ROE和分红率辅助判断 |
| 新业务18-22% | "转型早期，谨慎使用SOTP" | 降低执行风险折扣至25-30% |
| 周期顶部信号 | "当前PE处于历史低位，可能是周期顶部" | 优先使用正常化PE，降低仓位 |
| 亏损但增速<50% | "亏损股但增速不足，不符合终局估值条件" | 使用PB估值，等待盈利拐点 |
