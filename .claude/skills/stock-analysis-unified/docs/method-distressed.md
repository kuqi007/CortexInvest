# 困境股估值方法 (Method 6 - 困境反转)

> 适用: 全年仍盈利但利润较正常水平大幅下滑(>50%)，收入萎缩或停滞

## PE与PB冲突处理
若PE极高(>50x)但PB合理(1-4x):
1. 判断PE高是临时低迷还是结构性恶化
2. 临时低迷 → PB为主锚，PE仅参考
3. 结构性恶化 → PB主锚+额外折价
4. 不得因PE极高默认"泡沫"，也不得忽视利润恶化
5. PB与正常化PE差异>50% → 并列展示，不得取平均

## 核心公式
PB估值(主锚):
  目标价 = BPS × PB倍数
  PB倍数 = 行业可比PB × 质量调整系数

正常化PE(辅助):
  目标价 = 正常化EPS × 合理PE(15-25x)
  正常化EPS = 过去3-5年平均利润 / 总股本

安全买点 = 综合公允价值 × (1 - 安全边际30%)
注: 困境股安全边际默认30%，高于常规15-25%

## 风险检查清单
□ 收入连续2+年萎缩 → 折价+5%
□ 利润下滑来自主营 → 等待恢复信号
□ 现金流为负 → PB保留流动性折价
□ 行业政策周期底部 → 可适当乐观
□ 央企/国企背景 → PB取上半区
□ 资产负债率<40% → 资产价值有支撑
