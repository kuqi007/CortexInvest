# 统一报告模板参考 (Step 5)

> 完整模板 → 从 valuation_result.json 渲染人读报告

## 文件生成顺序

1. `valuation_result.json` — 结构化结果(truth source)
2. `{股票名}_v{N}_{日期}.md` — 人读报告
3. `metadata.json` — 索引摘要(从valuation_result投影)
4. 更新 `catalog.json` 的 latest_version
