# 转型股估值方法详解 (SOTP)

> **适用**: 新业务占比20-50%，旧业务衰退，多元化集团

---

## SOTP 估值步骤

### Step 1: 识别业务分部

**可拆分的标准**:
- 收入/利润可独立核算
- 有不同的增长率和盈利能力
- 处于不同生命周期阶段
- 适用不同的估值方法

**典型分部**:
```
传统业务: 成熟、低增长、稳定现金流 → PE/PB
新兴业务: 高增长、可能亏损 → PS/PEG
战略业务: 未盈利、高潜力 → 期权价值/PS
海外业务: 独立运营 → 分部估值
```

---

### Step 2: 为每个分部选择估值方法

| 分部类型 | 特征 | 估值方法 | 典型倍数 |
|----------|------|----------|----------|
| **成熟业务** | 利润稳定，增速<15% | PE | 10-15x |
| **成长业务** | 利润>30%，可预测 | PE/PEG | 20-30x |
| **超成长业务** | 利润>50%或亏损 | PS/EV | 5-15x |
| **周期业务** | 利润波动大 | 正常化PE/PB | 视周期 |
| **战略业务** | 未盈利，高潜力 | 期权价值 | 标的估值 |

---

### Step 3: 计算各分部估值

**分部利润归属**:
```
如果 公司有明确分部利润披露:
    使用披露数据
否则:
    估算分部利润 = 分部收入 × 估算利润率
    
    估算利润率来源:
    - 行业平均水平
    - 可比公司利润率
    - 公司历史分部数据
```

**分部利润估算方法** (当分部利润未明确披露时):

| 场景 | 估算方法 | 公式/方法 |
|------|----------|-----------|
| 分部收入+已知毛利率 | 应用行业利润率 | 分部利润 = 收入 × 行业平均利润率 |
| 仅分部收入 | 使用毛利率代理 | 分部利润 = 收入 × (公司整体毛利率 ± 调整) |
| 成长分部 | 利润率扩张法 | 从当前低利润率逐步提升至行业水平 |
| 成熟分部 | 利润率压缩法 | 使用历史平均或行业中位数 |

**费用分摊指导**:

| 费用类型 | 分摊基础 | 示例 |
|----------|----------|------|
| 公司管理费用 | 收入比例 | 分部A占60%收入 → 分摊60%管理费用 |
| 共享研发费用 | 战略重要性 | 按增长潜力加权，非仅按收入 |
| 销售管理费用 | 员工数或收入 | 按主导驱动因素分摊 |
| 融资成本 | 分部资产负债 | 按分部营运资本使用分摊 |

**关键计算要点**:
1. **所得税调整**: 盈利分部需扣除25%企业所得税，亏损部分不抵税
2. **亏损业务估值**: 亏损分部使用PB估值，而非PE
3. **估值倍数选择**: 成熟业务PE 15-25x，成长业务PE 40-80x或PS 8-15x

**详细计算示例** (东阳光2025年数据):

步骤1：估算各分部毛利
```
┌──────────────┬────────┬────────┬────────────────┐
│     业务     │ 收入   │ 毛利率 │    毛利        │
├──────────────┼────────┼────────┼────────────────┤
│ 化工新材料   │ 40.6亿 │ 43.33% │    17.6亿      │
│ 铝箔         │ 59.2亿 │  4.12% │     2.4亿      │
│ 电子元器件   │ 35.6亿 │ 22.0%  │     7.8亿      │
├──────────────┼────────┼────────┼────────────────┤
│ 合计         │ 135.4亿│        │    27.8亿      │
└──────────────┴────────┴────────┴────────────────┘
```

步骤2：分摊期间费用
- 期间费用合计约20亿（销售+管理+研发+财务）
- 按收入比例分摊：化工30% → 6亿，铝箔44% → 8.8亿，电子26% → 5.2亿

步骤3：估算税后分部利润
```
┌──────────────┬────────┬────────┬────────┬────────┬────────┐
│     业务     │  毛利  │ 分摊费用│ 税前利润│ 税后利润│ 估值   │
├──────────────┼────────┼────────┼────────┼────────┼────────┤
│ 化工新材料   │ 17.6亿 │  6亿   │ 11.6亿 │ 8.7亿  │ PE 20x │
│ 铝箔         │  2.4亿 │  8.8亿 │ -6.4亿 │ -6.4亿 │ PB 0.5x│
│ 电子元器件   │  7.8亿 │  5.2亿 │  2.6亿 │ 1.95亿 │ PE 40x │
├──────────────┼────────┼────────┼────────┼────────┼────────┤
│ 合计         │ 27.8亿 │  20亿  │  7.8亿 │ 4.25亿 │   -    │
└──────────────┴────────┴────────┴────────┴────────┴────────┘
```

**简化示例** (东阳光，基于实际财务数据):

| 分部 | 收入 | 利润 | 估值方法 | 倍数 | 估值 |
|------|------|------|----------|------|------|
| 传统制冷剂 | 40-50亿 | 4-5亿 | PE | 12x | 48-60亿 |
| AI算力 | 15-20亿 | 0.5亿 | PS | 8-10x | 120-200亿 |
| 铝箔 | 50-60亿 | 盈亏平衡 | PB | 1.0x | 约30亿 |
| **SOTP毛估值** | - | - | - | - | **198-290亿 (中性240亿)** |

> **注**: 铝箔业务在详细测算中显示亏损（PB 0.5x），简化示例按盈亏平衡（PB 1.0x ≈ 30亿）处理，实际估值时应根据最新财务数据判断。

---

### Step 4: 应用执行风险折扣

**转型阶段判断**:

| 阶段 | 新业务占比 | 折扣率 | 理由 |
|------|-----------|--------|------|
| 早期 | <20% | 25-35% | 不确定性高，新业务发展未定 |
| 中期 | 20-40% | 15-25% | 增长可见，但执行风险仍存 |
| 晚期 | >40% | 5-15% | 转型基本成功，风险较低 |
| 失败风险 | 占比下降 | 40-50% | 旧业务衰退，新业务未起 |

---

### Step 5: 应用安全边际

**转型股额外要求**:
```
安全目标价 = SOTP净估值 × (1 - 安全边际)

安全边际:
- 早期转型: 25-30%
- 中期转型: 15-25%
- 晚期转型: 10-15%
```

---

## 完整计算示例 (东阳光)

| 项目 | 金额 | 说明 |
|------|------|------|
| SOTP毛估值 | 198-290亿 | 中性约240亿 |
| 执行风险折扣 -20% | -40至-58亿 | 转型中期 |
| SOTP净估值 | 158-232亿 | - |
| 安全边际 -20% | -32至-46亿 | - |
| **最终估值** | **126-186亿** | **中性约155亿** |
| 总股本 | 30.1亿股 | - |
| **目标价** | **4.2-6.2元** | **中性约5.1元** |

**vs 机构目标价35元**: 差异主要来自：
1. AI业务PS倍数(我们用8-10x vs 机构15-20x)
2. 执行风险折扣(我们用20% vs 机构10-15%)
3. 安全边际(我们用20% vs 机构5-10%)

## 数据质量层级

SOTP可靠性取决于数据质量:

| 层级 | 数据可用性 | 估值可靠性 | 建议 |
|------|-----------|-----------|------|
| **Level 1** | 分部收入+利润均披露 | 高 | 直接使用 |
| **Level 2** | 分部收入+毛利率披露 | 中高 | 估算运营利润 |
| **Level 3** | 仅分部收入 | 中 | 行业利润率估算 |
| **Level 4** | 无分部数据 | 低 | **不宜用SOTP** |

---

## 与机构估值差异处理

**常见差异原因**:

| 因素 | 我们的假设 | 机构假设 | 影响 |
|------|-----------|----------|------|
| 分部利润 | 保守估算 | 乐观估算 | ±20-30% |
| 估值倍数 | 历史中枢 | 可比溢价 | ±20-30% |
| 执行风险 | 20-30%折扣 | 10-15%折扣 | ±15-20% |
| 安全边际 | 15-25% | 5-10% | ±10-20% |

**总差异**: 机构估值通常比我们高 **50-100%**
