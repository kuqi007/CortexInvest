# 转型股估值方法详解 (SOTP)

> **适用**: 新业务占比20-50%，旧业务衰退，多元化集团；或刚完成重大并表、需要把分部估值与前瞻盈利口径同时展示的公司

---

## SOTP 估值步骤

### Step 0: 先区分三种价格

在转型股估值里，必须把三个概念分开：

| 名称 | 定义 | 用途 |
|------|------|------|
| **毛估值** | 各分部估值直接加总 | 看业务拆分是否合理 |
| **公允价值** | 毛估值扣执行风险后的结果 | 用来和机构目标价、市场定价比较 |
| **安全买点** | 公允价值再扣安全边际 | 用来确定建仓区间 |

**硬规则**:
- 不得将"安全买点"直接写成"目标价"后与机构目标价比较
- 如存在重大并表 / pro forma 场景，必须再补一套 Forward PE / PEG / EV 口径

### Step 1: 识别业务分部

**可拆分的标准**:
- 收入/利润可独立核算
- 有不同的增长率和盈利能力
- 处于不同生命周期阶段
- 适用不同的估值方法

**典型分部**:
```
传统业务: 成熟、低增长、稳定现金流 → PE/PB
新兴业务: 高增长、可能亏损 → PS/PEG
战略业务: 未盈利、高潜力 → 期权价值/PS
海外业务: 独立运营 → 分部估值
```

---

### Step 2: 为每个分部选择估值方法

| 分部类型 | 特征 | 估值方法 | 典型倍数 |
|----------|------|----------|----------|
| **成熟业务** | 利润稳定，增速<15% | PE | 10-15x |
| **成长业务** | 利润>30%，可预测 | PE/PEG | 20-30x |
| **超成长业务** | 利润>50%或亏损 | PS/EV | 5-15x |
| **周期业务** | 利润波动大 | 正常化PE/PB | 视周期 |
| **战略业务** | 未盈利，高潜力 | 期权价值 | 标的估值 |

---

### Step 3: 计算各分部估值

**分部利润归属**:
```
如果 公司有明确分部利润披露:
    使用披露数据
否则:
    估算分部利润 = 分部收入 × 估算利润率
    
    估算利润率来源:
    - 行业平均水平
    - 可比公司利润率
    - 公司历史分部数据
```

**分部利润估算方法** (当分部利润未明确披露时):

| 场景 | 估算方法 | 公式/方法 |
|------|----------|-----------|
| 分部收入+已知毛利率 | 应用行业利润率 | 分部利润 = 收入 × 行业平均利润率 |
| 仅分部收入 | 使用毛利率代理 | 分部利润 = 收入 × (公司整体毛利率 ± 调整) |
| 成长分部 | 利润率扩张法 | 从当前低利润率逐步提升至行业水平 |
| 成熟分部 | 利润率压缩法 | 使用历史平均或行业中位数 |

**费用分摊指导**:

| 费用类型 | 分摊基础 | 示例 |
|----------|----------|------|
| 公司管理费用 | 收入比例 | 分部A占60%收入 → 分摊60%管理费用 |
| 共享研发费用 | 战略重要性 | 按增长潜力加权，非仅按收入 |
| 销售管理费用 | 员工数或收入 | 按主导驱动因素分摊 |
| 融资成本 | 分部资产负债 | 按分部营运资本使用分摊 |

**关键计算要点**:
1. **所得税调整**: 盈利分部需扣除25%企业所得税，亏损部分不抵税
2. **亏损业务估值**: 亏损分部使用PB估值，而非PE
3. **估值倍数选择**: 成熟业务PE 15-25x，成长业务PE 40-80x或PS 8-15x

**重大收购 / pro forma 处理**:
1. 若过去12个月内已完成交割或高度确定交割，必须单列"并表资产"分部
2. 若收购价可见，优先把收购价 / EV 作为估值锚，而不是继续沿用旧收入假设
3. 必须补充 pro forma 口径:
   - 并表后收入
   - 并表后 EBITDA / 净利润
   - 并表后总股本或潜在稀释
4. 若并表资产占总估值 >30%，SOTP 结果只能视为静态公允价值，不足以单独解释市场定价

**详细计算示例** (东阳光2025年数据):

步骤1：估算各分部毛利
```
┌──────────────┬────────┬────────┬────────────────┐
│     业务     │ 收入   │ 毛利率 │    毛利        │
├──────────────┼────────┼────────┼────────────────┤
│ 化工新材料   │ 40.6亿 │ 43.33% │    17.6亿      │
│ 铝箔         │ 59.2亿 │  4.12% │     2.4亿      │
│ 电子元器件   │ 35.6亿 │ 22.0%  │     7.8亿      │
├──────────────┼────────┼────────┼────────────────┤
│ 合计         │ 135.4亿│        │    27.8亿      │
└──────────────┴────────┴────────┴────────────────┘
```

步骤2：分摊期间费用
- 期间费用合计约20亿（销售+管理+研发+财务）
- 按收入比例分摊：化工30% → 6亿，铝箔44% → 8.8亿，电子26% → 5.2亿

步骤3：估算税后分部利润
```
┌──────────────┬────────┬────────┬────────┬────────┬────────┐
│     业务     │  毛利  │ 分摊费用│ 税前利润│ 税后利润│ 估值   │
├──────────────┼────────┼────────┼────────┼────────┼────────┤
│ 化工新材料   │ 17.6亿 │  6亿   │ 11.6亿 │ 8.7亿  │ PE 20x │
│ 铝箔         │  2.4亿 │  8.8亿 │ -6.4亿 │ -6.4亿 │ PB 0.5x│
│ 电子元器件   │  7.8亿 │  5.2亿 │  2.6亿 │ 1.95亿 │ PE 40x │
├──────────────┼────────┼────────┼────────┼────────┼────────┤
│ 合计         │ 27.8亿 │  20亿  │  7.8亿 │ 4.25亿 │   -    │
└──────────────┴────────┴────────┴────────┴────────┴────────┘
```

**简化示例** (东阳光，更新后示意口径):

| 分部 | 收入 | 利润 | 估值方法 | 倍数 | 估值 |
|------|------|------|----------|------|------|
| 化工新材料 | 40-45亿 | 6-8亿 | PE | 12-18x | 72-144亿 |
| 电子元器件 | 35-40亿 | 3-5亿 | PE | 18-28x | 54-140亿 |
| 高端铝箔 | 55-60亿 | 低利润 | PB | 0.8-1.3x | 24-50亿 |
| 算力资产 / 秦淮数据 | 并表口径 | EBITDA 25-30亿 | EV/EBITDA | 10-15x | 250-375亿 |
| 新兴业务(液冷/机器人) | 早期 | - | 期权价值 | - | 20-50亿 |
| **SOTP毛估值** | - | - | - | - | **420-760亿 (中性约590亿)** |

> **注**: 这是为了说明口径变化。像东阳光这样已出现重大并表的案例，不应继续沿用"AI收入15-20亿、PS 8-10x"的老示例。

---

### Step 4: 应用执行风险折扣，得到公允价值

**转型阶段判断**:

| 阶段 | 新业务占比 | 折扣率 | 理由 |
|------|-----------|--------|------|
| 早期 | <20% | 25-35% | 不确定性高，新业务发展未定 |
| 中期 | 20-40% | 15-25% | 增长可见，但执行风险仍存 |
| 晚期 | >40% | 5-15% | 转型基本成功，风险较低 |
| 失败风险 | 占比下降 | 40-50% | 旧业务衰退，新业务未起 |

---

### Step 5: 应用安全边际，得到安全买点

**转型股额外要求**:
```
安全目标价 = SOTP净估值 × (1 - 安全边际)

安全边际:
- 早期转型: 25-30%
- 中期转型: 15-25%
- 晚期转型: 10-15%
```

---

### Step 6: 重大并表时追加前瞻平台估值

当满足以下任一条件时，必须追加 Forward PE / PEG / EV 估值：
- 并表资产占总估值 > 30%
- 次年利润预测较当前报表口径抬升 > 50%
- 机构研报普遍采用 2026E / 2027E 估值

**计算框架**:
```
前瞻平台估值 = Forward EPS × 目标PE
或
前瞻平台估值 = Forward净利润 × 目标PE
或
前瞻平台估值 = Forward EBITDA × EV/EBITDA
```

**输出要求**:
1. 先给出 SOTP公允价值
2. 再给出 前瞻平台估值
3. 最后解释两者差异来自:
   - 静态资产价值 vs 前瞻盈利能力
   - 并表协同是否计入
   - 估值倍数是否切换到成长平台口径

## 完整计算示例 (东阳光，更新口径)

| 项目 | 金额 | 说明 |
|------|------|------|
| SOTP毛估值 | 420-760亿 | 中性约590亿 |
| 执行风险折扣 -10%至-20% | -40至-120亿 | 并表整合期 |
| **公允价值** | **450-560亿** | 中性约500亿 |
| 安全边际 -15%至-20% | -70至-110亿 | 用于建仓保护 |
| **安全买点对应市值** | **360-470亿** | 中性约410亿 |
| 总股本 | 30.1亿股 | - |
| **公允价值** | **15-19元/股** | 中性约16.5元 |
| **安全买点** | **12-16元/股** | 中性约13.5元 |
| 2026E净利润 | 18-20亿 | 机构前瞻假设区间 |
| Forward PE 50-60x | 900-1200亿 | 成长平台口径 |
| **平台估值** | **30-40元/股** | 与机构目标价更可比 |

**vs 机构目标价35元**: 差异主要来自：
1. 我们的SOTP公允价值反映的是静态分部价值，机构更多反映前瞻平台价值
2. 机构采用 2026E PE / PEG，已把并表后的盈利跃迁和协同预期计入
3. 安全买点只用于建仓，不应作为与机构目标价对比的口径

## 数据质量层级

SOTP可靠性取决于数据质量:

| 层级 | 数据可用性 | 估值可靠性 | 建议 |
|------|-----------|-----------|------|
| **Level 1** | 分部收入+利润均披露 | 高 | 直接使用 |
| **Level 2** | 分部收入+毛利率披露 | 中高 | 估算运营利润 |
| **Level 3** | 仅分部收入 | 中 | 行业利润率估算 |
| **Level 4** | 无分部数据 | 低 | **不宜用SOTP** |
| **Level 5** | 重大并表但缺pro forma口径 | 低 | **必须补做Forward估值，SOTP仅作参考** |

---

## 与机构估值差异处理

**常见差异原因**:

| 因素 | 我们的假设 | 机构假设 | 影响 |
|------|-----------|----------|------|
| 对比口径 | 我们常用SOTP公允价值/安全买点 | 机构常用Forward PE/PEG | 差异可达50%+ |
| 分部利润 | 保守估算 | 乐观估算或并表后利润 | ±20-30% |
| 估值倍数 | 历史中枢 | 可比溢价 / 平台溢价 | ±20-30% |
| 执行风险 | 10-30%折扣 | 5-15%折扣 | ±10-20% |
| 安全边际 | 15-25% | 通常不单独披露 | ±10-20% |

**总差异**: 若机构采用前瞻平台口径，估值通常会比SOTP公允价值高 **50-100%**；若再把我们的安全买点拿去比，差异会被进一步放大
