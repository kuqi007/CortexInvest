# 转型股估值方法详解 (SOTP)

> **适用**: 新业务占比20-50%，旧业务衰退，多元化集团；或新业务占比处于18-22%的转型早期但结构变化已很明显；或刚完成重大并表、需要把分部估值与前瞻盈利口径同时展示的公司

---

## SOTP 估值步骤

### Step 0: 先区分三种价格

在转型股估值里，必须把三个概念分开：

| 名称 | 定义 | 用途 |
|------|------|------|
| **毛估值** | 各分部估值直接加总 | 看业务拆分是否合理 |
| **公允价值** | 毛估值扣执行风险后的结果 | 用来和机构目标价、市场定价比较 |
| **安全买点** | 公允价值再扣安全边际 | 用来确定建仓区间 |

**硬规则**:
- 不得将"安全买点"直接写成"目标价"后与机构目标价比较
- 如存在重大并表 / pro forma 场景，必须再补一套 Forward PE / PEG / EV 口径

### Step 1: 识别业务分部

**可拆分的标准**:
- 收入/利润可独立核算
- 有不同的增长率和盈利能力
- 处于不同生命周期阶段
- 适用不同的估值方法

**典型分部**:
```
传统业务: 成熟、低增长、稳定现金流 → PE/PB
新兴业务: 高增长、盈利稳定时看PEG，未稳定盈利时看PS
战略业务: 未盈利、高潜力 → 期权价值/PS
海外业务: 独立运营 → 分部估值
```

> **口径提醒**: 这里的"成熟业务 PE 15-25x"是分部可比口径，用于 SOTP 拆分；不等同于整家公司作为价值股时的历史 PE 中枢。

---

### Step 2: 为每个分部选择估值方法

| 分部类型 | 特征 | 估值方法 | 典型倍数 |
|----------|------|----------|----------|
| **成熟业务** | 利润稳定，增速<15% | PE | 15-25x |
| **成长业务** | 利润>30%，可预测 | PE/PEG | 20-30x |
| **超成长业务** | 利润>50%或亏损 | PS/EV | 5-15x |
| **周期业务** | 利润波动大 | 正常化PE/PB | 视周期 |
| **战略业务** | 未盈利，高潜力 | 期权价值 | 标的估值 |

---

### Step 3: 计算各分部估值

**分部利润归属**:
```
如果 公司有明确分部利润披露:
    使用披露数据
否则:
    估算分部利润 = 分部收入 × 估算利润率
    
    估算利润率来源:
    - 行业平均水平
    - 可比公司利润率
    - 公司历史分部数据
```

**分部利润估算方法** (当分部利润未明确披露时):

| 场景 | 估算方法 | 公式/方法 |
|------|----------|-----------|
| 分部收入+已知毛利率 | 应用行业利润率 | 分部利润 = 收入 × 行业平均利润率 |
| 仅分部收入 | 使用毛利率代理 | 分部利润 = 收入 × (公司整体毛利率 ± 调整) |
| 成长分部 | 利润率扩张法 | 从当前低利润率逐步提升至行业水平 |
| 成熟分部 | 利润率压缩法 | 使用历史平均或行业中位数 |

**费用分摊指导**:

| 费用类型 | 分摊基础 | 示例 |
|----------|----------|------|
| 公司管理费用 | 收入比例 | 分部A占60%收入 → 分摊60%管理费用 |
| 共享研发费用 | 战略重要性 | 按增长潜力加权，非仅按收入 |
| 销售管理费用 | 员工数或收入 | 按主导驱动因素分摊 |
| 融资成本 | 分部资产负债 | 按分部营运资本使用分摊 |

**关键计算要点**:
1. **所得税调整**: 默认用25%企业所得税估算；若公司明确享受高新技术企业/区域优惠税率，应优先用公司真实有效税率或分部可验证税率
2. **亏损业务估值**: 亏损分部使用PB估值，而非PE
3. **估值倍数选择**: 成熟业务PE 15-25x，成长业务常规PE 20-30x，超成长或盈利未稳阶段优先用PS/EV 5-15x
   - 若业务已满足高成长平台口径，溢价应主要体现在 Forward PE / PEG / EV 中，而不是在 SOTP 分部里重复给 40x+ 高倍数
4. **税务口径提醒**: 分部亏损不应机械按"不抵税"处理；若集团层面存在可结转亏损、税盾或合并纳税影响，必须在说明中单列

**利润质量桥接（估值前置检查）**:
1. 必须先区分 `报表归母净利润`、`扣非归母净利润`、`调整后经营利润`
2. 若三者差异明显，必须追查来源：
   - 公允价值变动 / 金融资产价格波动
   - 资产减值 / 存货跌价 / 信用减值
   - 资产处置 / 出售股权 / 卖资产
   - 投资收益 / 权益法收益 / 理财收益
   - 股权激励等一次性费用
   - 政府补助 / 其他收益 / 汇兑收益损失 / 并购重组费用
3. 估值解释规则：
   - `公允价值变动 / 金融资产波动`：可单列经营趋势利润观察，但不能完全无视；应在股东口径估值中保留风险折价
   - `资产处置 / 一次性出售收益`：不得当作主营成长利润外推，也不得据此提高PE/PEG倍数
   - `减值`：若确属低频且不影响主业盈利能力，可辅助观察经营趋势；但若反映资产质量恶化，则不能简单加回
   - `政府补助 / 其他收益`：必须区分经常性与一次性，不能默认全部视作主营利润
   - `并购费用 / 重组费用`：可单列观察经营趋势，但若并购整合风险高，不能因此取消执行风险折扣
4. 最终报告必须说明：哪个利润口径用于公允价值主锚，哪个口径仅作辅助观察

**重大收购 / pro forma 处理**:
1. 若过去12个月内已完成交割或高度确定交割，必须单列"并表资产"分部
2. 若收购价可见，优先把收购价 / EV 作为估值锚，而不是继续沿用旧收入假设
3. 必须补充 pro forma 口径:
   - 并表后收入
   - 并表后 EBITDA / 净利润
   - 并表后总股本或潜在稀释
4. 若并表资产占总估值 >30%，SOTP 结果只能视为静态公允价值，不足以单独解释市场定价

### Step 2.5: 可比公司 PS 锚定（v1.8 新增，转型股和亏损股必做）

**目的**: SOTP分部PS倍数不得凭感觉设定，必须有可比公司锚定。

**步骤**:

1. **从 mx-search 提取可比PS**:
   - 搜索研报文本中列出的同行PS倍数
   - 正则: `r'([\u4e00-\u9fa5]{2,6}(?:\d{4}\.\w+)?)\s*(?:的)?PS\s*(?:为|约)\s*([0-9.]+)\s*x?'`
   - 每个提取到的PS必须标注口径（TTM / FY1）

2. **不足2家时补充mx-data查询**:
   - 用已识别的可比公司代码（如 02556.HK）额外调用 mx-data
   - 获取: 总市值 + 营业收入 → 计算 PS = 市值/收入
   - 或者直接取 PS 指标（如果有）

3. **输出可比估值表**:

| 可比公司 | 代码 | PS(TTM) | PS(FY1) | 口径 | 数据来源 |
|---------|------|---------|---------|------|---------|
| 微盟集团 | 02013.HK | 6.5x | — | TTM | mx-search |
| 迈富时 | 02556.HK | 5.8x | 4.0x | TTM/FY1 | mx-search |
| ... | ... | ... | ... | ... | ... |
| **中位数** | — | **6.2x** | **4.0x** | — | — |

4. **PS倍数校准规则**:
   ```
   if 有3家以上可比公司:
       分部PS = 可比中位数 × 调整系数(0.8-1.3)
       调整系数依据: 增速差异/毛利率差异/市场地位差异
   elif 有1-2家可比公司:
       分部PS = 可比均值 × 调整系数(0.7-1.2)
       标注"可比数据有限，PS置信度降低"
   else:
       使用 method-lossmaking.md 的默认增速分级PS表
       标注"无同行可比，PS使用默认分级表"
   ```

5. **硬规则**:
   - PS口径不一致时（TTM vs FY1），对亏损/高增长公司优先用 FY1 PS
   - 对成熟稳定业务优先用 TTM PS
   - 不得将 Palantir 等美股公司 PS 直接用于中国公司，必须打折（流动性+市场差异）

**分部拆解说明**:
- 正式报告可以展示"分部毛利 → 分摊费用 → 税前利润 → 税后利润"的推导过程
- 该过程只用于说明 SOTP 如何拆分，不应绑定任何真实公司、年份或固定倍数
- 分部成长业务若已需要 40x+ 高倍数解释，通常应转入 Forward PE / PEG / EV 层，而不是继续留在 SOTP 分部静态估值里

> **勾稽提醒**: 分部税后利润拆解只是说明思路，不能默认等同于合并报表归母净利润。正式报告必须补充说明总部费用、内部抵消、少数股东损益、递延税项、金融资产公允价值波动等合并调整，否则只能把分部加总视作 SOTP 中间过程，而不是报表复刻值。

**通用结构示例** (重大并表 / 转型股):

| 分部 | 利润口径 | 估值方法 | 倍数/锚定 | 说明 |
|------|----------|----------|-----------|------|
| 成熟业务A | 稳态净利润 | PE | 历史中枢或可比中位数 | 传统业务，低增长 |
| 成长业务B | 扣非净利润或经营趋势利润 | PE/PEG | 需先确认利润质量 | 不能把一次性利润当成长利润 |
| 低盈利业务C | 低利润/亏损 | PB/正常化利润 | 避免机械套高PE | 周期或资产密集型业务 |
| 并表资产D | EBITDA/净利润 | EV/EBITDA 或 Forward PE | 优先参考收购价、可比和一致预期 | 必须说明是否考虑稀释与少数股东 |
| 新兴期权业务E | 暂未盈利 | 期权价值/PS | 仅作小权重补充 | 不得主导总估值 |
| **SOTP毛估值** | - | - | - | 仅为分部求和中间过程 |

> **注**: 这里只展示结构，不提供真实公司数值。实际执行时，必须基于当期数据重算，不得沿用文档示例数字。

---

### Step 4: 应用执行风险折扣，得到公允价值

**转型阶段判断**:

| 阶段 | 新业务占比 | 折扣率 | 理由 |
|------|-----------|--------|------|
| 早期 | <20% | 25-35% | 不确定性高，新业务发展未定 |
| 中期 | 20-40% | 15-25% | 增长可见，但执行风险仍存 |
| 晚期 | >40% | 5-15% | 转型基本成功，风险较低 |
| 失败风险 | 占比下降 | 40-50% | 旧业务衰退，新业务未起 |

**折扣应用提醒**:
- 处于重大并表整合期时，通常仍按中期转型处理，常见折扣区间 15-25%
- 若使用低于15%的折扣，必须明确说明依据，例如并表协同已经兑现、订单和利润口径已验证
- 不得一边采用极低执行风险折扣，一边再套成长平台最高倍数而不给解释

---

### Step 5: 应用安全边际，得到安全买点

**转型股额外要求**:
```
安全买点 = SOTP净估值 × (1 - 安全边际)

安全边际:
- 早期转型: 25-30%
- 中期转型: 15-25%
- 晚期转型: 10-15%
```

---

### Step 6: 重大并表时追加前瞻平台估值

当满足以下任一条件时，必须追加 Forward PE / PEG / EV 估值：
- 并表资产占总估值 > 30%
- 次年利润预测较当前报表口径抬升 > 50%
- 机构研报普遍采用 next fiscal year / next two fiscal years 估值

**计算框架**:
```
前瞻平台估值 = Forward EPS × 目标PE
或
前瞻平台估值 = Forward净利润 × 目标PE
或
前瞻平台估值 = Forward EBITDA × EV/EBITDA
```

**输出要求**:
1. 先给出 SOTP公允价值
2. 再给出 前瞻平台估值
3. 最后解释两者差异来自:
   - 静态资产价值 vs 前瞻盈利能力
   - 并表协同是否计入
   - 估值倍数是否切换到成长平台口径
   - 利润口径是否受公允价值变动、资产处置或一次性事项影响
4. Forward 口径必须额外说明:
   - 使用的是 报表归母 / 扣非归母 / 调整后经营利润 / EBITDA 中哪一个
   - 是否包含资产处置、公允价值波动、政府补助等一次性项目
   - 是否已考虑并表后股本稀释、可转债/期权摊薄、少数股东损益
   - 倍数锚定来自哪些可比公司或机构一致预期
5. 若前瞻平台估值与SOTP公允价值差异 > 2x:
   - 不得简单平均
   - 必须双轨并列展示，并解释差异来源

## 输出格式示意 (无个股数值)

| 项目 | 写法要求 | 说明 |
|------|----------|------|
| SOTP毛估值 | 列示分部估值区间或中性值 | 仅表示拆分后的静态求和值 |
| 执行风险折扣 | 明确折扣区间与阶段判断 | 说明为何适用早期/中期/晚期折扣 |
| **公允价值** | 给出市值区间和每股区间 | 这是与市场和机构可比的静态口径 |
| 安全边际 | 单列边际比例 | 不与执行折扣混写 |
| **安全买点** | 给出市值区间和每股区间 | 仅用于建仓，不用于对比机构目标价 |
| Forward利润/EBITDA | 明确年份与利润口径 | 必须写清是否扣非、是否稀释、是否含一次性 |
| Forward倍数 | 列示 PE/PEG/EV 及依据 | 必须给出可比公司或一致预期来源 |
| **平台估值** | 给出市值区间和每股区间 | 仅在重大并表/成长+转型时使用 |

**投资建议写法**:
1. 建仓区间只引用 `安全买点`
2. 静态目标区间只引用 `公允价值`
3. 平台目标区间只引用 `前瞻平台估值`
4. 若 `静态目标区间` 与 `平台目标区间` 差异 > 2x:
   - 不得合并成一个总目标区间
   - 必须写成双轨结论，并说明当前更看重静态价值还是平台兑现

**与机构对比的默认 headline 规则**:
1. 若机构研报明确主要采用 next-year PE / PEG / EV，则默认 headline 对比 `平台估值`
2. 若机构研报主要采用分部法 / NAV / 资产重估，则默认 headline 对比 `公允价值`
3. 若无法判断机构口径:
   - 默认先展示 `公允价值`
   - 再补展示 `平台估值`
   - 不得为了贴近机构目标价而事后挑选更高的一侧做 headline

**与机构对比的标准写法**:
1. 先对比 `公允价值` 或 `平台估值`
2. 单列说明 `安全买点` 只是建仓口径
3. 若平台估值明显高于SOTP公允价值，必须解释差异来自:
   - 静态资产价值 vs 前瞻盈利能力
   - 并表协同是否已兑现
   - 利润口径是否剔除一次性项目
   - 倍数是否切换到成长平台口径

## 数据质量层级

SOTP可靠性取决于数据质量:

| 层级 | 数据可用性 | 估值可靠性 | 建议 |
|------|-----------|-----------|------|
| **Level 1** | 分部收入+利润均披露 | 高 | 直接使用 |
| **Level 2** | 分部收入+毛利率披露 | 中高 | 估算运营利润 |
| **Level 3** | 仅分部收入 | 中 | 行业利润率估算 |
| **Level 4** | 无分部数据 | 低 | **不宜用SOTP** |
| **Level 5** | 重大并表但缺pro forma口径 | 低 | **必须补做Forward估值，SOTP仅作参考** |

## 与机构估值差异处理

**常见差异原因**:

| 因素 | 我们的假设 | 机构假设 | 影响 |
|------|-----------|----------|------|
| 对比口径 | 我们用于对比的是SOTP公允价值或前瞻平台估值，安全买点仅用于建仓 | 机构常用Forward PE/PEG | 差异可达50%+ |
| 分部利润 | 保守估算 | 乐观估算或并表后利润 | ±20-30% |
| 估值倍数 | 历史中枢 | 可比溢价 / 平台溢价 | ±20-30% |
| 执行风险 | 10-30%折扣 | 5-15%折扣 | ±10-20% |
| 安全边际 | 15-25% | 通常不单独披露 | ±10-20% |

**总差异**: 若机构采用前瞻平台口径，估值通常会比SOTP公允价值高 **50-100%**；若再把我们的安全买点拿去比，差异会被进一步放大
