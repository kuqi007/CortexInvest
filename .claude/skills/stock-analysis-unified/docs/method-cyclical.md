# 周期股估值方法详解

> **适用**: 大宗商品、航运、建筑、化工等周期行业

---

## 周期行业清单

| 行业 | 典型细分 | 周期驱动因素 |
|------|----------|--------------|
| **钢铁** | 板材、长材、特钢 | 基建投资、房地产、制造业 |
| **煤炭** | 动力煤、焦煤 | 电力需求、钢铁产量、进口政策 |
| **航运** | 干散货、油运、集运 | 全球贸易、船舶供给、燃油成本 |
| **化工** | 基础化工、石油化工、农化 | 原油价格、下游需求、环保政策 |
| **建材** | 水泥、玻璃、玻纤 | 房地产、基建、错峰生产 |
| **有色金属** | 铜、铝、锌、锂 | 全球需求、库存水平、新能源需求 |
| **造纸** | 包装纸、文化纸 | 消费需求、废纸价格、产能周期 |
| **工程机械** | 挖掘机、起重机 | 房地产、基建、更新周期 |
| **重卡** | 整车、发动机 | 物流需求、排放标准、替换周期 |

---

## 周期位置判断

### 关键指标

| 指标 | 底部 | 顶部 | 正常 |
|------|------|------|------|
| 行业产能利用率 | <70% | >90% | 75-85% |
| 行业ROE | <5% | >20% | 8-12% |
| 龙头PE | 亏损或>50x | <5x | 10-15x |
| 龙头PB | <0.8x | >2.5x | 1.0-1.5x |
| 行业资本开支 | 大幅削减 | 大幅扩张 | 维持 |

---

## 估值方法

### 1. 正常化PE (Normalized PE)

**适用于**: 周期正常或底部

```
正常化利润 = 过去5-7年平均利润（剔除极端年份）
或
正常化利润 = 行业平均ROE × 公司净资产

目标价 = 正常化利润 × 目标PE

目标PE:
- 周期底部: 12-15x (复苏预期)
- 周期正常: 10-12x
- 周期顶部: 8-10x (防见顶)
```

### 2. PB Band

**适用于**: 周期底部（最可靠）

```
保守PB = 历史PB 10分位数
中性PB = 历史PB 25分位数  
乐观PB = 历史PB 中位数

目标价 = 每股净资产 × PB
```

**周期底部PB通常<1**，提供安全边际。

### 3. 重置成本

**适用于**: 资产重的周期股（钢铁、水泥、航运）

```
重置成本 = 重建相同产能所需的资本开支
估值 = 重置成本 × 折扣系数

折扣系数:
- 严重过剩: 0.5-0.7
- 轻度过剩: 0.7-0.9
- 供需平衡: 0.9-1.1
```

### 4. 股息率 (周期顶部)

**适用于**: 周期顶部逃顶判断

```
如果 股息率 < 2% 且 PE < 5x:
    信号 = 周期顶部，考虑减持

历史规律: 周期股在PE最低时往往最危险
```

## 分周期阶段估值权重

| 阶段 | 主方法 | 权重 | 辅助方法 | 权重 |
|------|--------|------|----------|------|
| **BOTTOM** | PB | 50% | 重置成本 | 30% |
| **NORMAL** | 正常化PE | 70% | PB Band | 30% |
| **TOP** | 正常化PE | 50% | 股息率 | 30% |

## 输出格式

| 情景 | 周期假设 | 估值方法 | 目标价 |
|------|----------|----------|--------|
| 保守 | 周期延长 | PB 0.8x | XX元 |
| 中性 | 正常周期 | 正常化PE 11x | XX元 |
| 乐观 | 周期复苏 | 正常化PE 13x | XX元 |

## 特别警示

### 周期股估值陷阱

1. **低PE陷阱**: 周期顶部PE最低，但最危险
   - 例: 某钢铁股PE 3x，但随后利润暴跌80%

2. **高PE陷阱**: 周期底部PE极高或为负，但可能机会
   - 例: 某航运股亏损，PB 0.6x，随后复苏涨3倍

3. **"这次不一样"**: 每个周期都有人认为旧规律不适用
   - 坚持: 均值回归是周期股铁律
