# 价值股估值方法详解

> **适用**: 利润低增长或平稳增长（通常0-15%），稳定分红，成熟行业

> **边界提醒**: 若扣非/经营趋势利润增速约等于15%（如 14.5%-15.5%），不要直接当作标准价值股处理，应先回到主文档 `SKILL.md` 的 15-30% 过渡区规则判断。

---

## 核心指标

| 指标 | 标准 |
|------|------|
| 利润增速 | 0-15%（约15%先看过渡区） |
| ROE | >10% |
| 股息率 | >2% |
| 行业 | 成熟、竞争格局稳定 |

---

## 估值方法

### 1. PE Band (市盈率)

```
目标价 = EPS × PE倍数

PE倍数选择:
- 保守: 历史PE 10分位数 (通常8-10x)
- 中性: 历史PE 25分位数 (通常10-12x)
- 乐观: 历史PE中位数 (通常12-15x)
```

### 2. PB Band (市净率)

```
目标价 = BPS × PB倍数

PB倍数估算:
- 基础PB = 合理PE × ROE
  例: ROE 15%，合理PE 10x → PB = 0.15 × 10 = 1.5x

- 或简化方法 (基于ROE):
  * ROE > 15%: PB 1.5-2.0x
  * ROE 10-15%: PB 1.0-1.5x
  * ROE < 10%: PB 0.8-1.2x

质量系数调整 (±0.2):
+ ROE > 15%: +0.2
+ 分红率 > 50%: +0.1
+ 负债率 < 40%: +0.1
- 利润波动 > 30%: -0.2
```

### 3. 股息率模型

```
目标价 = 每股股息 / 目标股息率

目标股息率:
- 高质量价值股: 3%
- 稳健价值股: 4%
- 防御型价值股: 5%
```

### 4. 清算价值

```
清算价值 = 可变现资产 - 负债
安全边际价格 = 清算价值 × 0.7
```

## 输出格式

| 情景 | PE倍数 | PB倍数 | 目标价 |
|------|--------|--------|--------|
| 保守 | 8-10x | 0.8-1.0x | XX元 |
| 中性 | 10-12x | 1.0-1.2x | XX元 |
| 乐观 | 12-15x | 1.2-1.5x | XX元 |

---

## 关键假设检查

1. **利润稳定性**: 过去5年利润波动 < 30%
2. **分红持续性**: 连续分红 > 3年
3. **行业地位**: 行业前三或细分领域龙头
