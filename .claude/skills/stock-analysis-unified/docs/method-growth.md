# 成长股估值方法详解

> **适用**: 利润增速>30%，可预测性强

---

## 核心指标

| 指标 | 超成长 | 质量成长 | 稳健成长 |
|------|--------|----------|----------|
| 利润增速 | >50% | 30-50% | 15-30% |
| 收入增速 | >50% | >30% | >15% |
| 毛利率 | >40% | >35% | >30% |
| ROE | >15% | >12% | >10% |

---

## 估值方法

### 1. PEG (PE/Growth)

```
合理PE = 利润增长率 × PEG目标

PEG目标:
- 超成长(>50%): 1.0-1.5
- 质量成长(30-50%): 0.8-1.2
- 稳健成长(15-30%): 0.6-1.0

目标价 = EPS × 合理PE
```

**示例**: 增速40%，PEG 1.0 → 合理PE = 40x

### 2. Forward PE

```
目标价 = Forward EPS × 目标PE

Forward EPS = 今年预期利润 / 总股本

目标PE:
- >50%增速: 50-80x
- 30-50%增速: 30-50x
- 15-30%增速: 20-30x
```

### 3. DCF (现金流折现)

```
企业价值 = Σ(FCFt/(1+r)^t) + 终值/(1+r)^n

参数:
- 预测期: 3-5年
- 增长率: 逐年递减至稳态
- 折现率: 10-12%
- 终值PE: 15-20x
```

### 4. 可比公司溢价

```
选取3-5家可比公司，计算平均PE/PB
考虑溢价/折价因素:
+ 增速领先: +10-20%
+ 毛利率领先: +10%
+ 市场地位领先: +10-15%
```

---

## 增速分级估值

| 增速 | PEG范围 | PE范围 | PS范围 |
|------|---------|--------|--------|
| >100% | 1.2-1.5 | 80-150x | 15-25x |
| 50-100% | 1.0-1.3 | 50-80x | 10-15x |
| 30-50% | 0.8-1.2 | 25-50x | 5-10x |
| 15-30% | 0.6-1.0 | 15-25x | 3-5x |

---

## 输出格式

| 情景 | 假设增速 | PE倍数 | 目标价 |
|------|----------|--------|--------|
| 保守 | 增速-10pp | PEG 0.8 | XX元 |
| 中性 | 预期增速 | PEG 1.0 | XX元 |
| 乐观 | 增速+10pp | PEG 1.2 | XX元 |

---

## 风险提示

1. **增速回落风险**: 高增速难以持续，PEG陷阱
2. **估值压缩风险**: 市场情绪变化导致PE收缩
3. **业绩miss风险**: 季度业绩不及预期引发的杀估值

## 输入字段溯源

> 数据提取方法见 `./docs/mx-data-field-mapping.md` 和 `./docs/mx-search-institutional-schema.md`

| 估值输入 | 来源 | 提取方法 |
|----------|------|---------|
| EPS(历史) | mx_data 年报文件 | 计算: 归母净利润(col `100000000003705`) × 1e8 / 总股本 × 1e4 |
| Forward EPS(FY1) | mx_data 年报预测table | col `100000000004890` / 总股本 |
| 扣非增速 | mx_data 年报文件 | col `100000000004687` 最新值 |
| 历史 PE 中枢 | 无本地数据 | 使用下方内置默认值 |

**内置历史 PE 中枢**（当 mx-data 无 PE Band 数据时使用）:
- 超成长(>50%): 40-60x（中值 50x）
- 质量成长(30-50%): 25-40x（中值 32x）
- 稳健成长(15-30%): 15-25x（中值 20x）

> **注**: EPS 无独立字段，需计算。若需精确历史 PE 分位，需单独查询 mx-data PE Band 数据文件。
