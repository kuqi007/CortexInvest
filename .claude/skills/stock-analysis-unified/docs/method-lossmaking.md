# 亏损股估值方法详解

> **适用**: 当前亏损但高增长 (收入增速>50%)

---

## 估值前提检查

**不适用PS估值的情况**:

| 情况 | 说明 | 替代方法 |
|------|------|----------|
| 收入也负增长 | 衰退而非成长 | 清算价值 |
| 收入质量差 | 一次性收入占比高 | 调整后收入 |
| 现金消耗过快 | runway < 12个月 | 融资后估值 |
| 无明确商业模式 | 概念炒作 | 不估值，回避 |

**适用PS估值的黄金标准**:
- 收入增速 > 50%
- 收入可预测、可重复
- 有清晰盈利路径
- 现金 runway > 18个月

---

## 估值方法

### 1. PS (市销率) - 核心方法

```
市值 = 收入 × PS倍数
目标价 = 市值 / 总股本
```

**PS倍数选择**:

| 收入增速 | 质量评级 | PS倍数范围 |
|----------|----------|-----------|
| >100% | ★★★★★ | 15-25x |
| 70-100% | ★★★★☆ | 10-15x |
| 50-70% | ★★★☆☆ | 6-10x |
| 30-50% | ★★☆☆☆ | 3-6x |

**质量调整因素**:
```
基础PS = 基于增速的基准倍数

调整项:
+ 毛利率高 (>70%): +20%
+ 现金流改善: +15%
+ 行业龙头: +10%
- 收入集中度高: -15%
- 现金消耗快: -20%
```

### PS 倍数可比校准（v1.8 新增）

上面的增速分级PS表是**默认基准**，不得直接使用，必须用可比公司校准：

**校准步骤**:
1. 从 mx-search 行业数据中提取至少 2-3 家可比公司的当前PS
2. 如果可比公司 PS 中位数与默认表差异 > 30%:
   - 以可比公司中位数为准
   - 标注"默认PS表与同行实际差异>30%，已校准"
3. 如果无可靠可比公司数据:
   - 使用默认表
   - 标注"PS无同行锚定，使用默认增速分级表"

**口径标注要求**:
- 每个引用的 PS 必须标注: TTM / FY1 / FY2
- 亏损公司（收入增速高但利润为负）优先使用 FY1 PS（前瞻口径更稳定）
- 不得将不同口径的 PS 直接平均

**美股公司折价规则**:
- Palantir/Snowflake 等美股SaaS公司 PS 不得直接用于中国公司
- 折价系数: 0.5-0.7（反映流动性差异、市场差异、盈利质量差异）
- 如果使用美股PS做锚，必须显式标注折价系数和理由

### 2. EV/Revenue

**适用于**: 有显著净债务或现金的公司

```
企业价值 (EV) = 市值 + 净债务
EV/Revenue = EV / 收入

更准确的比较指标，剔除资本结构差异
```

### 3. 终局估值 (Terminal Value)

**适用于**: 高确定性赛道 (如AI芯片、SaaS)

**计算步骤**:
```
Step 1: 估算TAM (总市场规模)
   TAM = 全球市场 × 可服务市场% × 可获取市场%

Step 2: 估算稳态市占率
   - 行业龙头: 20-30%
   - 细分龙头: 5-10%
   - 跟随者: 1-5%

Step 3: 估算稳态利润率
   - 软件/SaaS: 20-30%
   - 平台型: 15-25%
   - 硬件: 5-15%

Step 4: 估算稳态估值
   稳态利润 = TAM × 市占率 × 利润率
   稳态市值 = 稳态利润 × PE (通常15-20x)

Step 5: 折现到现值
   现值 = 稳态市值 / (1 + 折现率)^年数
```

**示例**:
```
TAM: 1000亿元
稳态市占率: 10%
稳态收入: 100亿元
稳态利润率: 20%
稳态利润: 20亿元
稳态PE: 20x
稳态市值: 400亿元
折现率: 15%
时间: 5年
现值: 400 / (1.15)^5 = 199亿元
```

### 4. 可比交易法

**适用于**: 近期有同行业并购交易

```
估值 = 可比交易估值 / 可比交易收入 × 目标公司收入

需调整因素:
- 收入增速差异
- 毛利率差异
- 市场地位差异
```

## 风险调整

### 现金消耗风险

```
Runway (月) = 现金余额 / 月均现金消耗

如果 runway < 12个月:
    估值折扣 = 30-50%
Elif runway < 18个月:
    估值折扣 = 15-25%
Else:
    估值折扣 = 0%
```

### 收入质量风险

```
经常性收入% = 经常性收入 / 总收入

如果 经常性收入% < 50%:
    收入调整系数 = 经常性收入% × 2
    调整后收入 = 收入 × 收入调整系数
```

## 特别警示

### 亏损股投资铁律

1. **必须有收入**: 无收入的概念股 = 赌博
2. **必须高增长**: 增速<50%的亏损股 = 价值陷阱
3. **必须有路径**: 看不到盈利路径 = 回避
4. **必须控仓位**: 单股仓位不超过10%

### 常见陷阱

| 陷阱 | 识别方法 | 应对 |
|------|----------|------|
| **收入造假** | 收入增长但应收账款激增 | 看现金流 |
| **补贴依赖** | 非经常性损益占利润大头 | 看扣非利润 |
| **关联方输血** | 关联交易占比高 | 看收入质量 |
| **概念炒作** | PPT公司，无实质产品 | 看客户案例 |
