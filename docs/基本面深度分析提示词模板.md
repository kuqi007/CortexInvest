# 股票基本面深度分析提示词模板

> 使用方式：复制下方内容，将 `{股票名}` 替换为目标股票，发给AI即可

---

## 提示词正文

```
你是一位专业的基本面分析师，请对 {股票名} 进行深度基本面分析。

## 第一步：基础信息收集

请先搜索并整理以下数据（不要跳过任何一项）：

1. 公司简介：主营业务、行业地位、股权结构、实际控制人
2. 最新行情：当前股价、总市值、流通市值、PE(TTM)、PB、PS
3. 股本结构：总股本、流通股本、每股净资产、每股未分配利润
4. 分红情况：近3年分红方案、累计分红、当前股息率

## 第二步：财务数据（必须覆盖近5年）

请整理以下指标的近5年趋势（按年度列出）：

| 指标 | 要求 |
|------|------|
| 营业收入 | 绝对值 + 同比增速 |
| 归母净利润 | 绝对值 + 同比增速 |
| 扣非归母净利润 | 绝对值 + 同比增速 |
| 毛利率 | 年度值 |
| 净利率 | 年度值 |
| ROE（净资产收益率） | 年度值 |
| 资产负债率 | 年度值 |
| 经营性现金流净额 | 绝对值，与净利润比较 |
| 研发费用及占收入比 | 绝对值 + 占比 |

同时请列出最近4个季度的单季度数据（营收、归母净利润、扣非净利润、毛利率），观察趋势变化。

## 第三步：利润质量桥接（必须做）

建立三层利润口径并对比：

1. 报表归母净利润
2. 扣非归母净利润
3. 调整后经营利润（如有必要）

如果归母净利润与扣非净利润差异明显（差异>20%或方向相反），必须分析差异来源并归类：
- A. 公允价值变动 / 金融资产价格波动
- B. 资产减值 / 信用减值 / 存货跌价
- C. 资产处置 / 出售股权
- D. 投资收益（权益法、处置收益、理财等）
- E. 股权激励 / 一次性费用
- F. 其他一次性或低频事项

明确说明：
- 哪个利润口径反映真实股东损益
- 哪个利润口径反映主营经营趋势
- 高增长是否来自主营，而非一次性收益

## 第四步：业务结构分析

1. 按产品/业务线的收入构成（金额+占比）
2. 按地区的收入构成
3. 各业务线的毛利率对比
4. 哪些业务在增长，哪些在衰退
5. 新业务/新增长点的进展和占比变化

## 第五步：行业与竞争

1. 公司所处行业的市场规模、增速、发展阶段
2. 行业竞争格局（CR3/CR5、公司市占率）
3. 3-5家主要竞争对手，对比收入、利润、估值
4. 行业核心驱动力和未来趋势
5. 行业政策环境

## 第六步：机构观点

搜索并整理：
1. 近6个月覆盖该股的机构研报（机构名、日期、评级）
2. 机构对今明后三年的盈利预测（收入、净利润）
3. 机构给出的目标价
4. 机构一致预期

## 第七步：估值分析

根据前面分析判断公司类型，选择对应估值方法：

### 如果是价值股（增速<15%，ROE>10%，稳定分红）
- PE Band估值：历史PE中枢、当前分位
- PB估值：PB vs ROE关系
- 股息率模型（如适用）

### 如果是成长股（扣非增速>30%，增长来自主营）
- PEG估值：合理PE = 增速 × PEG目标
- Forward PE：基于明年预测EPS
- 与可比公司PE对比

### 如果是周期股
- 先判断周期位置（底部/正常/顶部）
- 正常化PE：用5-7年平均利润
- PB估值（底部适用）

### 如果是转型股（新业务占比20-50%）
- SOTP分部估值：每个业务线分别估值再加总
- Forward PE交叉验证

### 如果是亏损股
- PS估值（收入增速>50%时适用）
- PB估值（资产价值支撑）

无论用哪种方法，都必须输出：
- 保守/中性/乐观三档估值
- 公允价值区间
- 安全买点（公允价值再打20-25%折扣）

### 敏感性分析
列出对估值影响最大的2-3个变量，分别±10%后观察估值变化。

## 第八步：综合结论

请用以下结构输出最终结论：

### 1. 一句话定位
用一句话概括这是一家什么样的公司（业务+阶段+特点）

### 2. 三张表

**财务健康表**
| 维度 | 评分(1-5) | 说明 |
|------|-----------|------|
| 盈利能力 | | |
| 成长性 | | |
| 财务安全 | | |
| 现金流质量 | | |
| 分红回报 | | |

**核心指标表**
| 指标 | 当前值 | 行业对比 | 判断 |
|------|--------|----------|------|
| 营收增速 | | | |
| 利润增速 | | | |
| ROE | | | |
| PE(TTM) | | | |
| PB | | | |

**估值结论表**
| | 保守 | 中性 | 乐观 |
|--|------|------|------|
| 预计利润(今年) | | | |
| 预计利润(明年) | | | |
| 合理PE | | | |
| 目标市值 | | | |
| 目标价 | | | |
| 安全买点 | | | |

### 3. 投资建议
- 当前价格 vs 公允价值 vs 安全买点
- 评级：买入/增持/持有/减持/卖出
- 什么价格值得买
- 止损位建议

### 4. 看多逻辑（不超过3条，要具体）

### 5. 风险提示（不超过5条，要具体，按影响程度排序）

### 6. 关键跟踪指标（3-5个，告诉我后续要盯什么）

## 硬规则

1. 所有数据必须基于最新公开信息，不得使用1年前的旧数据
2. 不得用"可能"、"大概"敷衍，每个结论必须有数据支撑
3. 如果数据不足，直接说明"该项数据缺失"并标注对结论的影响
4. 估值不得为了好看而拔高倍数，必须说明倍数选择的依据
5. 如果公司有亏损业务或烧钱业务，必须单独列出其对利润的拖累金额
6. 如果利润高增长主要来自一次性收益（资产处置/投资收益/公允价值变动），不得直接按高增速给成长股估值
7. 最终报告不得只有数字，每个关键结论都要用大白话解释"这意味着什么"
```

## 使用示例

```
/基本面分析 兴森科技
/基本面分析 贵州茅台

```

只需把 `{股票名}` 替换为目标股票名即可。如果AI的第一次回答不够深入，可以追问：

- "利润质量桥接部分，归母和扣非的差异来源请具体到项目金额"
- "SOTP估值每个分部的假设请列得更细"
- "可比公司估值对比请具体列出数据"
- "敏感性分析请量化到±10%对目标价的影响"
