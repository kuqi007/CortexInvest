# 转型股估值方法 (Method 4 - SOTP)

> 适用: 新业务20-50%，旧业务衰退

## 核心公式
公允价值 = Σ(分部估值) × (1 - 执行风险折扣)
安全买点 = 公允价值 × (1 - 安全边际15-25%)

## SOTP分部估值步骤
1. **识别分部**: 成熟业务/成长业务/亏损业务/并表资产
2. **为每分部选方法**:
   - 成熟业务 → PE 15-25x
   - 成长业务 → PS/PE（看增速和盈利性）
   - 亏损业务 → PB/终局估值
   - 并表资产 → Forward PE/PEG
3. **计算各分部估值** → 加总 = SOTP毛估值
4. **应用执行风险折扣** → 公允价值
5. **应用安全边际** → 安全买点

## 双轨输出
若存在重大并表/pro forma:
- 静态: SOTP分部估值 → 公允价值
- 前瞻: Forward PE/PEG/EV → 平台估值
- 差异>2x → 并列展示，不得取平均

## 执行风险折扣 (默认25%)
```
最终折价率 = clamp(25% - 加价 + 打折, 10%, 40%)

加价因素(降低折扣):
  □ 新业务连续2Q盈利 → -5%
  □ 管理层成功转型历史 → -5%
  □ 新业务客户续约率>85% → -5%
  □ 转型路径清晰+量化里程碑 → -3%

打折因素(增加折扣):
  □ 新业务亏损无盈利时间表 → +5%
  □ 旧业务衰退>预期 → +5%
  □ 核心高管/创始人近期变动 → +5%
  □ 行业竞争加剧 → +5%
  □ 大额资本开支回报不确定 → +3%
  □ 治理评估有红灯(Step 2.5C) → +5%

示例:
  金山云 = 25% + 5%(旧业务衰退) + 5%(稀释) = 35%
  某SaaS盈利转型 = 25% - 5% - 5% = 15%
```

## 硬规则
- 不得无理由取最低值15%
- 不得跳过折扣率计算表直接输出数字
- ≥5个打折因素 → 标注"高风险，建议人工介入"
- 治理折价与执行风险折扣为叠加关系，非取大值
