> 版本：v2.2 | 日期：2026-04-18 | 状态：执行中

## 一、目录结构

```
ai-investor/
│
├── catalog.json                          ← 全局目录（代码→路径+名称）
│
├── stocks/
│   ├── 00700.HK_腾讯控股/                ← 代码.市场_股票名（唯一+可读）
│   │   ├── v1_2026-04-18/
│   │   │   ├── 腾讯控股_v1_2026-04-18.md            ← 报告（带名称，可辨）
│   │   │   ├── valuation_result.json                 ← 结构化分析结果
│   │   │   ├── metadata.json                         ← 索引摘要
│   │   │   └── data/                                 ← 原始数据
│   │   └── v2_2026-10-18/
│   │       └── ...
│   │
│   ├── 09988.HK_阿里巴巴-W/              ← 阿里巴巴
│   ├── 03896.HK_金山云/                  ← 金山云
│   ├── 600309.SH_万华化学/               ← 万华化学
│   └── ...
│
└── .editorconfig
```

**市场后缀**：`.HK` 港股 | `.SH` 沪市 | `.SZ` 深市

## 二、catalog.json

以代码为主键，跨市场代码做别名：

```json
{
  "schema_version": "1.0",
  "last_updated": "2026-04-18",
  "stocks": {
  "00700.HK": { "name": "腾讯控股", "latest_version": 1, "dir_name": "00700.HK_腾讯控股" },
  "09988.HK": { "name": "阿里巴巴-W", "latest_version": 1, "dir_name": "09988.HK_阿里巴巴-W" },
  "01211.HK": { "name": "比亚迪股份", "latest_version": 1, "dir_name": "01211.HK_比亚迪股份" },
  "03690.HK": { "name": "美团-W", "latest_version": 1, "dir_name": "03690.HK_美团-W" },
  "03896.HK": { "name": "金山云", "latest_version": 1, "dir_name": "03896.HK_金山云" },
  "600309.SH": { "name": "万华化学", "latest_version": 1, "dir_name": "600309.SH_万华化学" }
  }
}
```

匹配逻辑：
1. 精确匹配代码 → 直接命中
2. 名称模糊匹配 → 返回候选列表让用户确认

匹配后通过 dir_name 定位实际目录路径。

## 五、Hermes Agent 工作流

```
用户：「分析腾讯控股」
  │
  ① 查 catalog.json
  │    代码精确匹配 / 别名匹配 / 名称模糊匹配(→候选确认)
  │
  ② 判断状态
  │    不存在 → 新建 00700.HK/
  │    存在 + 超过复盘周期 → 创建新版本
  │    存在 + 未过期 → 提示「上次分析 XX 天前」
  │
  ③ 数据采集 → data/
  │
  ④ Skill 分析 → valuation_result.json
  │
  ⑤ 渲染 → report.md + metadata.json
  │
  ⑥ 更新 catalog.json
```
