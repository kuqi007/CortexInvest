# 价值股估值方法 (Method 1)

> 适用: 利润低增长或平稳增长（通常0-15%），稳定分红，成熟行业

## 核心公式
目标价 = EPS × PE倍数（通常8-15x）
目标价 = BPS × PB倍数（ROE × 质量系数1.0-1.5）
高分红股: 目标价 = 每股股息 / 目标股息率（通常3-5%）

## 步骤
1. 收集近5年EPS/BPS/分红数据
2. 计算历史PE/PB中枢
3. 考虑分红稳定性、行业成熟度
4. 输出保守/中性/乐观三档目标价

## PE倍数参考区间
| 公司情况 | PE区间 |
|----------|--------|
| 超成熟行业，零增长 | 6-10x |
| 成熟稳定，增速0-5% | 8-12x |
| 稳健价值，增速5-10% | 10-15x |
| 高ROE(>15%)+稳定分红 | 15-20x |

## PB倍数参考区间
| ROE区间 | PB区间 | 说明 |
|---------|--------|------|
| ROE 8-12% | 0.8-1.2x | 合理 |
| ROE 12-18% | 1.2-1.8x | 良好 |
| ROE > 18% | 1.8-2.5x | 优秀 |

## 三档情景输出
| 情景 | PE/PB | 假设 |
|------|-------|------|
| 保守 | 历史低位-中位下沿 | PE下沿或PB 0.8-1.0x |
| 中性 | 历史中枢 | PE中位或PB 1.2-1.5x |
| 乐观 | 历史高位-中位上沿 | PE上沿或PB 1.5-2.0x |

## 金融股特殊规则
银行/保险/券商默认归入价值股，但须检查:
- 银行: NIM趋势、不良率、拨备覆盖率、资本充足率
- 保险: 综合成本率、新业务价值率、投资收益率
- 券商: ROE(自营占比高)、经纪业务市占率
