# 亏损股估值方法 (Method 5 - PS/终局)

> 适用: 当前亏损但高增长(收入增速>50%)

## PS方法
市值 = 收入 × PS倍数

| 收入增速 | PS区间 |
|----------|--------|
| >80% + 毛利率>60% + NRR>120% | 30-50x |
| 50-80% | 15-30x |
| 30-50% | 5-15x |

**三条件同时满足才可用30-50x区间**

## 终局估值
稳态市值 = TAM × 市占率 × 利润率 × PE
现值 = 稳态市值 / (1+折现率)^年数

## 风险检查
- 现金runway必须>12个月
- 收入质量(经常性收入占比)
- 盈利路径可见性

## 不适用场景
当前亏损且收入增速<=50%:
→ 归入"困境股/低增速亏损股"
→ 优先看PB/净资产/资产价值
→ 结论: "等待盈利拐点"

## PS倍数限制规则
- NRR数据不可获取 → 上限35x，标注"NRR数据缺失"
- 任一条件失效 → 压缩回原区间，不得维持高倍数
