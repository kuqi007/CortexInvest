# 周期股估值方法 (Method 3)

> 适用: 大宗商品、航运、建筑、化工

## 核心逻辑
先判断周期位置，再决定估值方法

| 周期位置 | 主方法 | 估值逻辑 |
|----------|--------|----------|
| 底部 | PB | 市值 < 重置成本，安全边际 |
| 正常 | 正常化PE | 5-7年平均利润 × 12x |
| 顶部 | 正常化PE+逃顶 | 利润高点不可持续 |

## 周期位置强制校验
1. 计算偏离度: 当前利润 / 5年平均利润
2. 计算商品价格分位: 当前价格近10年百分位
3. 强制触发规则:
   - IF 偏离度>130% AND PE<历史中位 → 🔴周期顶部
     → 必须用正常化利润，PE取区间下限，不得高于"持有"
   - IF 偏离度>130% AND 价格>80%分位 → 🔴双重顶部
     → 安全边际额外+10pp，报告标注⚠️周期顶部警示

## 正常化PE计算
正常化EPS = 过去5-7年平均利润 / 总股本
正常化PE = 正常化EPS × 合理PE(10-15x)

## 警示
周期顶部PE最低（危险），底部PE最高或为负（机会）
