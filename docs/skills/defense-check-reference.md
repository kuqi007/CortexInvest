# 估值前防守检查参考 (Step 2.5)

> A/B/C/D/E五项均为必做，不得跳过。

## A. 毛利率趋势分析

### 趋势判断
- 连续3年毛利率下降 → 🔴红灯: 竞争力恶化
- 毛利率波动>10pp/年 → 🟡黄灯: 成本结构不稳定
- 毛利率稳定或上升 → 🟢绿灯

### 分部毛利率检查 (转型股/多元业务必做)
- 各业务分部毛利率趋势
- 高毛利占比↓ + 低毛利占比↑ → 整体下降非转型阵痛
- 区分: 产能爬坡(暂时) vs 竞争加剧(结构性)

### 同行对比
- 公司毛利率 vs 行业TOP3平均
- 差距>10pp → 必须解释原因

### 对估值影响
- 🔴红灯: 估值倍数折价10-20%
- 🟡黄灯: 安全边际增加5-10pp

### 毛利率评分
```
得分 = clamp((当前毛利率 - 3年前毛利率) / 3年前毛利率, 0, 1)
"连续下滑": 近3完整财年依次递减，或近4报告期≥3同比↓YoY
例外: 新业务占比提升导致的毛利率↓ → 不触发降级
```

### 行业适配
| 行业 | 替代指标 | 红灯标准 |
|------|---------|----------|
| 银行 | 净息差(NIM) + 不良贷款率 | NIM收窄; 不良率↑ |
| 保险 | 综合成本率 + 新业务价值率 | 综合成本率>100% |
| 地产 | 毛利率 + 净负债率 | 毛利率↓+高杠杆 |
| 券商 | ROE(自营占比高) | ROE波动大 |
| SaaS/软件 | 毛利率 | <60% |
| 制造业 | 毛利率 | 标准规则 |
| 煤炭/矿业 | 吨煤毛利 + 长协比例 | 吨煤毛利连降2年; 长协<30% |
| AI/高成长科技 | 毛利率 + 研发费率 | 毛利率<40%且↓ |

## B. 竞争量化分析

### 7维评分表

| 维度 | 指标 | 强 | 中 | 弱 |
|------|------|-----|-----|-----|
| 市场地位 | 市占率排名 | TOP2 | TOP3-5 | TOP5外 |
| 定价权 | 产品溢价/价格变动 | 能提价 | 跟随 | 被动降价 |
| 技术壁垒 | 研发费率/专利 | >10% | 5-10% | <5% |
| 客户粘性 | 续约率/转换成本 | >90% | 70-90% | <70% |
| 规模优势 | 成本优势/采购力 | 明显 | 一般 | 无 |
| 进入壁垒 | 牌照/网络效应 | 高 | 中 | 低 |
| 生态绑定 | 平台依赖度/迁移成本 | 深度绑定 | 中度绑定 | 无绑定 |

### 评分规则
- ≥5项"强" → 竞争力强，可用中枢偏上倍数
- ≥4项"弱" → 竞争力弱，估值折价15-25%
- 其余 → 竞争力中等，行业中性倍数

### 竞争折价规则
1. 行业口径: 明确子行业，可比公司≥3家同子行业
2. 规模劣势:
   - 收入<龙头1/6 → 可比区间下半区
   - 龙头1/6~1/4 → 中间区
   - >龙头1/4 → 可用上半区
3. 增速修正: >龙头1.5x → 上调一档
4. 客户集中度: 20-30%→已在执行风险折扣; >50%→额外+3%

### 行业适配
- 银行: "技术壁垒"→风控能力; "客户粘性"→存款基础
- 金融股: "进入壁垒"通常为强，不应给过高评分
- 资源型央企: "技术壁垒"→资源储备质量; "定价权"→长协比例
- 生态绑定"强": 若为平台核心节点→溢价5-10%; 若仅为被动依赖方→不溢价

## C. 公司治理评估

### 6项检查

| 检查项 | 🔴红灯 | 🟡黄灯 |
|--------|--------|--------|
| 控股股东关联交易 | >30% | 10-30% |
| 管理层稳定性 | 创始人/CEO变动 | CFO/COO变动 |
| 股权质押 | >50% | 30-50% |
| 审计意见 | 非标意见 | 强调事项段 |
| 关键人风险 | 高度依赖单一人物 | - |
| 信息透明度 | 多次更正/补充公告 | - |

### 影响规则
- 1个红灯 或 ≥2黄灯 → 估值折价10-15%
- ≥2红灯 → 暂停估值或纯投机分析
- 全绿灯 → 不影响估值

### 治理折价与执行风险折扣关系
两层折扣为叠加关系，非取大值:
```
SOTP公允价值 = Σ(分部估值) × (1 - 执行风险折扣)
治理折价后 = SOTP公允价值 × (1 - 治理折价)
```
- 全绿灯 → 不施治理折价
- 1红灯 → 治理折价纳入执行风险折扣，不额外叠加
- ≥2红灯 → 执行风险取上限40%，不再叠加

## D. 股本稀释检查

### 检查内容
1. **已发生稀释**: 配股/增发/可转债转股/期权行权/合并发行
2. **预期稀释**: 已公告未执行融资/可转债未转股/期权池
3. **完全稀释股数** = 当前总股本 × (1 + 稀释比例)

### 披露分级
| 稀释比例 | 处理 |
|----------|------|
| <3% | 可忽略，提及即可 |
| 3-10% | 必须用完全稀释股数 |
| >10% | 必须单列"稀释影响分析" |
| >20% | 🔴红灯，大幅折价，标注"严重稀释风险" |

### 稀释质量评估
- 好的: 接近/溢价增发，用于战略收购 → 标注但不打折
- 中性: 折扣增发，一般用途 → 标注+按稀释后计算
- 差的: 大幅折价，用于还债/输血 → 标注+额外折价+3%

### 3年累计稀释>15% → 标注"长期稀释风险"

## E. ESG/政策风险评估

### 检查项

| 风险类型 | 🔴红灯 | 🟡黄灯 |
|----------|--------|--------|
| 行业政策风险 | 高(已立法执行) | 中(讨论中) |
| ESG评级 | 面临机构排除风险 | 有改善压力 |
| 转型资本开支 | 拖累长期ROE | 可控 |

### 对估值影响
- 🔴高风险: 折价10-20%，正常化利润须扣除政策影响
- 🟡中风险: 报告中单列"ESG/政策风险"
- 🟢低风险: 简要提及

### 硬规则
- 不得跳过
- 不得以"难以量化"为由跳过
